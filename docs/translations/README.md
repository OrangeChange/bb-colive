# 界面翻译清单

[下载翻译清单](ui-translation-list.csv)。文件使用带BOM的UTF-8编码，可用Excel、WPS或文本工具打开。

简体中文是文案基准。当前表已填写繁体中文、英文、日语三列；修订时只修改这三列，保留标识、原文和其他列。没有确认的译文留空，不用中文原文占位。

- 标识是导回代码的依据，不修改、不合并；相同中文在不同位置可能有不同含义。
- 使用位置提供页面或功能上下文；多个位置使用同一条文案时列在同一单元格。
- `{name}`、`{count}`等变量保留名称，可以随语序移动，不能翻译或删掉。原生菜单和后台提示使用Rust格式，`{}`、`{error}`、`{:?}`及其中的格式说明均须保留。
- 保留必要的换行、首尾空格、文件扩展名、URL、CSS属性名和代码示例。界面文案不支持HTML，不额外插入标签。
- 短按钮、单位、悬停提示与长说明的长度要求不同，以使用位置核对；不要为了缩短而删掉必要的操作后果。
- BB CoLive、B站、OBS、Fish Audio、Blivechat、LAPLACE Chat和作者名称保持原名。

本清单只包含软件操作界面。事件内部的文字、状态、身份信息、时间、金额、名单操作，以及弹幕、昵称、礼物名、内置事件样例、播报模板、试听内容、用户填写的名称与备注、导出数据格式、许可正文不参与翻译。

软件默认显示简体中文，可在设置 → 通用 → 界面语言中切换繁体中文、英文与日文。具体归属和切换规则见[界面文案](../development/interface-localization.md)。

同步至语言资源后运行`npm run translations:check`，修复报告的缺失标识、空白文案和参数差异。清单中尚未确认的空白不能直接作为源码译文交付；已约定省略的量词除外。构建会自动执行同一检查。

更新清单：在项目根目录运行 `npm run translations:export`。该命令根据四份语言资源和实际引用更新清单。清单本身不会自动导入软件；审核后的修改须同步至对应语言资源。

## 统一术语

| 中文 | English | 繁體中文 | 日本語 |
| --- | --- | --- | --- |
| 房管 | Mod | 房管 | モデレーター |
| 大航海 | Membership | 大航海 | 大航海 |
| 成就 | Achievement | 成就 | 実績 |
| 荣耀等级／勋章 | Wealth level / Wealth medal | 榮耀等級／勳章 | 栄耀レベル／メダル |
| 红包 | Redpocket | 紅包 | 紅包 |
| 个性播报 | Custom audio | 個人化播報 | カスタム音声 |
| 粉丝牌 | Fan medal | 粉絲牌 | ファンメダル |
| 盈利／亏损 | Gain / Loss | 獲利／虧損 | 利益／損失 |
| 回看 | History | 直播紀錄 | 履歴 |

英文按句意区分Membership与Member，例如Member count和Member entry。日文说明可将大航海解释为有料メンバーシップ，将红包注为紅包（ホンバオ）；紧凑标签保留专有名称。公开DOM类、配置标识和已有数据字段不随界面译名改动。

英文和日文的历史界面使用History／履歴，主播档案使用Streamer history／配信者の履歴。范围、最低等级、删除与覆盖后果保留完整含义；计数量词按上下文省略，未读数量的new继续保留。
