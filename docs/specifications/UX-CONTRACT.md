# UX Contract

## Product context

- Audience: 在 Windows 桌面环境中持续观察直播现场的操作者
- Primary jobs: 连接直播间、读取事件流、筛选事件并调整多个展示窗口
- Active locales: zh-CN
- Accessibility target: WCAG 2.2 AA

## Visual contract

- Project `DESIGN.md`: 记录视觉层级、字号、间距、主题和副窗口规则
- Token ownership model: `DESIGN.md` 与 `src/App.css` 共同维护；运行时语义变量由 `src/App.css` 提供
- Runtime design-system/token source: `src/App.css`、`src/theme.ts`、`src/generalSettings.ts`
- Supported themes: 樱花粉（默认）／青瓷绿／自定义，系统／浅色／深色模式

## 规范化 UI/UX 语言

本文件是交互行为和组件归属的权威契约；视觉尺寸、色彩和动效数值以 `DESIGN.md` 为准。新增页面或控件必须先回答“它属于哪个任务、由哪个组件负责、状态变化后哪些内容必须保持”，再开始实现。

### 用户可见语言

- 软件操作界面文案集中维护于 `src/i18n/zh-CN.json`，当前只显示简体中文；修改界面文案同步更新语言资源与翻译清单。状态、图标和错误处理使用固定标识，不依赖中文标签。
- 所有事件内部、播报模板与试听内容、用户数据、主题名称及导出数据格式不参与界面翻译；具体边界见[界面文案](../development/interface-localization.md)。

- 统一使用“现场、回看、主播档案、单场、事件检索、右侧工作台、弹幕窗、收益窗、设置、样式、系统提醒”等名称。
- 标题和按钮表达对象与动作；辅助说明只说明范围、后果或下一步；错误说明发生了什么和下一步怎么处理。
- 同一概念不能在不同页面换名；不向用户暴露“业务事件、档案仓库、source/render”等内部实现术语。
- 设置页的普通说明保持短小；需要长期查看的状态放在控件附近，需要补充解释但不应占据布局的内容放到字段悬停提示。样式是左侧导航中的独立主工作区，设置页不重复提供入口。

### 交互不变量

- 设置、筛选、菜单和样式编辑器打开或关闭时，不重建连接、不清空事件、不重置筛选、不改变已保存阅读位置。
- 回看面包屑按固定层级导航：“全部主播”始终打开档案馆首页；单场主播名始终打开该场所属主播档案，保留该主播已记忆的筛选、模式和阅读位置。面包屑目的地不随历史入口变化；真实返回动作继续按浏览历史返回。
- 查询条件只影响所属任务：现场筛选不投影到回看，弹幕窗筛选不改变主窗口和日志，事件视觉设置同步到规定的展示区域。
- 右侧工作台是主窗口的扩展区域；设置不能迁移到左侧导航。弹幕窗和收益窗是主窗口控制的只读外置展示渠道，不能因为主窗口内容更详细而取消。
- 现场、回看、语音、个性播报和样式保持同级主工作台；不把不同任务强行合并成一条总事件流。
- 浮层点击外部或 Escape 收回；点击选择器触发器的第二次操作只收起该选择器，不误关父级筛选。浮层必须处理视口边缘、长中文选项和独立滚动。
- 鼠标、键盘和中文输入法路径必须得到同等结果。焦点始终可见，方向键/Home/End/Enter/Escape 的语义由控件类型统一定义。
- 布局根据容器实际可用宽度决定并排或换行；不要用屏幕截图宽度写死断点。分段控件按最长选项保留宽度，放不下时整组换行并占满可用宽度。
- 动效服务于状态和层级，不阻塞操作；遵循项目统一时长和 `prefers-reduced-motion`，用户事件行进入/退出动效只由事件显示设置控制。

### 组件选择顺序

1. 少量互斥选项使用 `src/components/SettingsChoiceControl.tsx` 的连体分段选择；保留原生单选语义和键盘行为，圆点视觉隐藏。长列表和字体选项使用 `src/components/ui/Select.tsx` 的 `UiSelect`。
2. 需要输入、过滤、最近搜索或关键词建议使用 `src/components/ui/Combobox.tsx` 的 `UiCombobox`。
3. 语音输出设备使用 `src/components/SettingsListSelect.tsx` 的自绘列表，因为它需要动态刷新和不可用设备提示。
4. 日期时间字段保留平台原生输入，这是明确的日期选择器边界。
5. 新控件必须复用项目语义令牌、焦点样式、portal 浮层、选中标记、外部关闭和减少动效规则；不能直接套用 HeroUI、Mantine 或浏览器原生弹层的默认皮肤。

### 新增功能的最小契约

新增设置或页面时，必须同时确定：

- 唯一归属的页面和分类；
- 默认值、恢复默认边界和持久化范围；
- 与连接、事件、筛选、阅读位置的关系；
- 窄工作台、长中文、禁用态、空态、错误态和异步等待态；
- 鼠标、键盘、输入法、点击外部和 Escape 的行为；
- 需要的动效、减少动效表现和验证用例。

未满足这些边界的控件不能作为局部“临时样式”合入。

## 契约与功能文档

本契约定义跨页面组件归属、交互一致性与状态保持。具体功能默认值、字段与数据口径按[功能文档](../README.md#功能文档)维护，版本进度见[项目状态](../project-status.md)，阶段证据见本地历史验收记录。

事件展示共用 `EventRow` 与身份组件；主题预览按现场、弹幕窗、收益窗和 OBS 消费真实排版与主题显示设置，回看不参与主题切换。“当前设置／全部部件”只切换局部预览，不修改已保存主题。公共结构与样式接口由[原生事件 DOM 与样式契约](../development/native-event-style-contract.md)唯一维护。

内置主题和自定义主题共用 `NativeThemeEditor`、可视化属性模型、Monaco 配置与预览链路。主题只保存一个基准字号和部件相对关系；现场、副窗口与每个 OBS 配置分别保存显示缩放，主题切换、导出和导入不改写目标缩放。可视化编辑的通用／浅色／深色覆盖与高级编辑中的受支持 CSS 声明双向同步；局部更新不得重写未知规则、表达式、单位、注释或规则顺序。短暂无效 CSS 保留草稿，预览保持最近有效结果。

颜色入口统一负责透明、纯色、透明度、HEX／RGBA／HSLA 精确输入和可用时的系统取色；预览棋盘或模拟纯色不进入任何运行目标。高级 CSS 的查找替换、跳转、格式化、注释、补全、折叠、诊断和编辑历史由 Monaco 内部命令负责；外层只保留明确的工作流动作。切换可视化 CSS、自定义 CSS 或预览状态时，分别保留草稿、选区、滚动位置和撤销历史。

“显示头像框”唯一归属为样式 → 原生样式 → 元素显示，默认开启；与头像开关及大航海标记模式分开保存，应用主题时同步现场、副窗口和 OBS。“全部部件”预览放开事件范围，头像、头像框、其他信息元素与打码仍服从当前设置，不修改保存主题。框和媒体回退保留固定尺寸；当前房间档位晚到同步两副窗已有事件，不重投事件、不续停留时间，回看只使用事件保存的里程碑，缺失时基础框。

## Canonical UI Map

### 主题调整与 OBS 输出契约

本节定义目标行为，实现与验收状态见 [项目状态](../project-status.md)与[样式功能文档](../features/themes-and-editor.md)。

- 主题默认基准与个人调整分开保存，均位于程序 `style` 目录。日常保存只写个人调整，不覆盖基准。基础设置保存字段覆盖；可视化和自定义 CSS 保存对应层的完整编辑结果，未编辑与明确清空须区分。继续使用既有三层 CSS。
- 内置主题基准为当前版本随附内容；导入、新建和另存主题分别以导入、创建及另存时内容为基准。已有主题缺少原始版本时，以其现有内容建立基准，不宣称可恢复遗失的历史版本。
- 编辑自动保留草稿，重启后恢复文档、代码和素材；恢复默认只更新可撤销草稿，基础恢复不清除 CSS。应用保存主题并刷新全部既有引用，不建立新绑定；无引用时只保存。无效 CSS 保留原文并阻止应用与导出。
- 原生与兼容编辑器共用草稿保留中、草稿已保留、保留失败及已保存状态；失败提供重试。保存中允许继续编辑，完成后仍有较新草稿时保留草稿状态；首次保存和另存为的命名弹窗在写入期间锁定输入、保存和关闭操作，失败后恢复操作。
- 历史事件首次检索失败时，重试保留原条件；清除条件继续作为独立操作。云端连接信息读取失败时提供重新查询，不把读取失败解释为需要重新填写身份码。
- 内置主题信息只读，不提供另存入口；主题编辑页允许保存个人调整与另存。导出和另存提供当前完整有效内容，接收端不依赖原机个人调整目录。
- OBS 配置以稳定 8 位短码标识，默认地址为 `/obs?config=<短码>`；同配置改名、换房间或主题保持地址不变。旧 UUID 配置标识一次性转换并同步快照引用，不保留 UUID 地址别名；原配置值与快照内容保留，旧链接需重新复制。
- OBS 地址可用 `room` 覆盖房间，用 `mode=light` 或 `mode=dark` 覆盖明暗；未指定时使用已保存配置，覆盖不反写。配置删除或地址错误须明确提示，不切换到默认配置。
- 每项 OBS 配置独立保存跟随软件／浅色／深色，默认跟随软件。现场跟随软件；副窗口具有独立明暗选择并默认跟随软件。预览明暗仅影响预览，独立预览窗口与固定 `/preview` 同步该选择，各页面阅读位置独立。
- LAPLACE 输出明暗优先级：链接明确值 > 配置固定值 > 跟随模式下有效 OBS 场景状态 > 软件明暗。有效场景含 `[dark]` 为深色、不含为浅色；场景信息不可用才回到软件明暗。主题场景与明暗分别解析。
- 明暗只选择主题已有规则，不改来源 CSS 或强制反色。OBS 网页宿主背景始终透明；主题自身卡片背景保留，预览棋盘与模拟底色不输出。

中奖名单由共享 `LotteryWinnerList` 负责；现场列表和回看时间线独立启用展开，用户名仅在有UID及用户筛选回调时可筛选。无回调用户名为文字；副窗及其他历史摘要宿主保留只读摘要。展开／收起保留原事件、筛选和阅读状态，经既有槽位测量更新行高。公共结构见原生事件样式契约。

## Component behavior

- 所有副窗口恢复有效的已保存几何，不依赖自定义标记；默认排放只用于首次创建及显式恢复布局。收益窗总关时，侧栏和设置的共享锁定均禁用并保留原状态，总开后恢复可用。

- 收益窗口显示方式唯一归属为设置 → 副窗口 → 收益窗，默认组合窗口，复用标准设置行与 `SettingsChoiceControl`。“开启收益窗”为总开关；三个子开关置于“分窗”组。侧栏收益窗原入口保持总开关，礼物、醒目留言、大航海 SVG 子按钮与共享锁定置于同一横向展开栏，总关时也能通过悬停或键盘焦点展开，复用收益窗原有收起时序。总开关恢复最近非空子窗组合；最后一个子窗关闭时总开关关闭，保留该非空组合。子按钮点击切换自身开关，悬停和焦点不改变开关。模式和选择保存在本机，窗口锁定共享，后开窗口继承；几何分别保存，恢复布局覆盖组合窗及三个子窗。首次及恢复分窗布局避让弹幕窗实际位置，关闭时读取保存位置，无保存时使用默认弹幕列；优先左侧，放不下时尝试右侧，容量限制见[副窗口布局](../features/auxiliary-windows.md#布局)。旧默认布局的整组识别与更新按同篇文档执行。模式切换保持房间、事件采集、筛选和主窗口分区。

- 固定展示唯一归属为设置 → 副窗口；默认与持久化规则见[副窗口固定展示](../features/auxiliary-windows.md#置顶栏)，位置与排序复用 `UiSelect`。固定卡片是只读投影，关闭功能及切房清空候选；原生窗口关闭保留主端有效候选，重开只恢复剩余寿命，普通日志保留原关闭策略。SC撤回同步普通行的删除状态并移除固定卡片。固定区无候选不留空区域，寿命提示仅通过可读属性提供。

- 设置面板通过顶部分类导航和滚轮切换分类；分类切换不重建连接、不清空事件、不重置筛选。只有正文区域滚动，顶部分类导航与收起按钮保持固定；帮助说明、焦点切换和弹窗关闭不能带动外层框架滚动。
- App 持久挂载 `VoicePanel` 与 `PersonalBroadcastPanel`，主区域切换使用 `hidden`；登录后的四个主面板共用切换容器，底部 `StatusBar` 固定在容器之外，不随当前面板切换或重复渲染，新主面板也必须接入该共享壳层。登录与恢复页面不显示底栏。语音正式队列、个性播报正式队列和连接状态不因页面切换而重置。个性播报试听仍使用独立的单槽打断通道。
- 声音输出只在设置 → 语音与播报中修改；语音与个性播报读取同一份收听范围和设备状态。“跟随系统默认设备”不写入当前设备 ID，后端开始下一次播放时重新解析系统默认设备；手动设备选择保持固定。
- 语音与个性播报侧栏入口都使用相同的悬停／键盘展开快捷开关；展开后的快捷按钮只切换自身播报开关，不改变另一个播报系统。
- 事件行更多菜单在悬停和 `:focus-within` 时显示右缘 glow 与操作入口；菜单通过 portal 定位并限制最大高度，点击外部或 Escape 收回。“查看上下文”只在现场/回看确有筛选条件时出现：现场清除文字和用户查询后定位原分类流；回看清除非分类筛选，仅保留主分类、细分分类及包含/排除状态后按稳定 eventKey 定位。无用户的系统事件保留菜单但将用户相关动作置灰。手动语音动作进入正式 TTS 队列，自动事件的开关、阈值和筛选不因该动作改变。
- 大航海身份的 UI 唯一组件是 `GuardIdentityBadge`，事件行统一覆盖现场主窗口、回看时间线/检索结果、弹幕副窗口和礼物副窗口；排行榜普通列表也复用同组件，并遵循同一份“显示大航海标记”开关和图标/文字模式。连接时读取房间级 `anchor_guard_achieve_level`：低于1000为普通套系，1000至9999为千舰增强套系，10000及以上为万舰增强套系；字段缺失时使用普通套系并标记未知，不阻断连接。事件用户保存该房间级档位，回看直接复用，不按单条事件重新判断。当前房间原始资料明确返回 URL 时优先显示该 URL；同房间、同 UID 后续消息缺少 URL 时沿用本连接已观测的原始 URL；切房不继承其他房间缓存；榜单 API 为该用户直接返回的 URL 优先。远程图缺失或加载失败时，按已解析的房间套系与身份等级使用随软件打包的对应图标；切换到“文字”显示身份名称，图标模式不回退文字。样式预览只有在本场确实捕获到带 URL 的身份数据时，才添加对应同一用户的实测样例。右上角前三个小头像只显示头像，不显示身份徽标。
- 昵称按 UID 维护在事件交互设置中，事件渲染层替换可见名称，筛选仍使用原始 UID/用户名；TTS 的用户名字段遵循同一解析器，并由“朗读昵称/用户名”控制是否输出。昵称列表使用有界滚动容器，避免设置页随条目数量无限增高。
- 现场事件的菜单“语音播报”只加入 TTS 正式队列，不触发个性播报；试听通道才使用单槽打断策略，正式事件队列仍保持原顺序。
- 收藏事件持久化完整事件快照和稳定事件键，重复点击切换收藏状态；明确场次持久键优先，晚到连击编号不改变原行身份。现场、回看、收藏页共用提交与同步入口，写入失败恢复目标状态且不通知成功，提交后刷新失败显示“已保存，刷新失败”。首次收藏时间、备注与标签保留；历史收藏不猜测原场归属。标记以信息流区域为键，每个区域只有一个当前位置，新标记替换旧标记。回看使用 SQLite 保存完整原始事件和收藏，时间线默认新到旧并可切换旧到新；数据导出默认顺序排列，Excel／CSV 可切换，JSON 固定顺序，标记不进入档案。
- 回看主播档案卡使用独立的置顶按钮；按钮在悬停、键盘聚焦和触屏布局下均可达，置顶偏好保存在本机设置中，置顶主播排在未置顶主播之前，不进入档案导出包。
- 主播档案的场次列表支持复选框、全选当前列表、已选数量、清除选择和批量删除；场次导航按钮与复选框保持同级，避免嵌套交互控件。记录中、重连中的场次不可选择删除，全选仅选已停止场次，刷新后移除恢复记录的旧选择。批量删除继续使用精确场次集合、影响预览和应用内二次确认；当前列表超过加载上限时明确提示“全选”只作用于当前列表。
- 回看管理的导出先生成完整 JSON 预览范围，资源只保存 URL，导入按 eventKey 幂等补缺并明确冲突/无法关联数量；删除先生成影响预览，确认后才级联删除场次、事件、收藏和阅读位置。单场、多选、保留策略及存储层执行均保护记录中、重连中的场次；已停止场次需二次确认后删除，保护独立于直播状态和记录质量。
- 列表、详情、历史边界、筛选和导出共用直播状态（进行中／已结束／状态未知）、记录状态（记录中／重连中／已停止）及记录质量（待确认／完整／不完整）。已结束不包含未知；质量选择器使用“记录质量”。黄色只合并明确缺口，灰色说明停止与场次信息；恢复撤去停止条并保留缺口。关闭按场次和原因集合记忆到本次窗口会话，顺序变化不重显，新原因可重显，独立提示互不影响。尚未加载场次不生成身份缺失提示，保存中和失败提示保持独立。
- 主播档案页以“场次/事件检索”分段切换两种互斥的查询任务：场次模式筛标题、开播时间、生命周期、质量和收藏；事件模式按事件时间、分类、关键词、身份、粉丝牌、礼物价格和收藏筛候选事件。两套筛选分别按主播记忆，排序按各自模式跨主播记忆。切换模式不清空另一侧条件或已加载结果；事件结果按场次分组并通过“加载更多场次”追加，点击摘要使用稳定 eventKey 定位，且不覆盖该场原阅读锚点。
- 在记录房间 A 时检索主播 B，A 的录档不触发 B 重新查询，也不打断 B 的“加载更多场次”。收藏提交继续跨入口更新检索结果和计数；收藏、整理或档案管理变更重新载入首屏并重置分页位置，已不命中的分组移除。刷新替代分页后，当前查询完成或失败均结束加载；旧请求不会覆盖结果或清除后续查询的加载状态。
- 固定选项不使用浏览器原生 `select` 或 `datalist`：少量互斥选项使用 `SettingsChoiceControl`，其余现场和设置表单、字体选择使用 `UiSelect`，关键词建议使用 `UiCombobox`；语音设备使用项目内 `SettingsListSelect`，保留动态设备与不可用设备提示。控件统一负责尺寸、选项对比度、选中标记和键盘焦点；浮层选择器另外负责列表宽度、位置和外部点击收起。字体选项统一使用菜单字体，不在下拉选项中逐项实时预览。日期时间字段仍使用平台原生日期输入。
- 高级筛选共用 `ReviewFilterPopover`，不共享条件或阅读状态。分类按钮 ArrowDown/Home 进入首项、ArrowUp/End 进入末项；Escape 关闭子层并回焦，外部点击逐层关闭。普通弹窗循环 Tab 并在关闭时返回触发焦点；导出忙碌时禁止外部、Escape 和关闭按钮关闭。中文输入法组合期间不处理菜单快捷键。设备首字匹配不改变选择；图片失败关联当前 URL，新 URL 重新加载。
- 标题栏退出和托盘退出均等待在途导出、档案刷盘、副窗关闭准备、诊断接收及最终刷盘；两次窗口等待各最多 3 秒，未完成不标 clean。隐藏到托盘保留连接和副窗。诊断历史累计写入异常与当前 failed/pending/dropped 分开显示，导出提示使用实际路径与最终缺失项。
- 设置分类和副窗口筛选控件保留可见焦点、主题色 hover/active 状态；窄面板中的双列筛选自动堆叠。
- 回看查询、导入、导出、删除和阅读位置恢复都记录 request/success/failure/cancel 生命周期；UI 与服务层共享 requestId，重复边界只在动作摘要中计数一次，详细诊断仍保留 source/render 关联。回看导出包和完整日志包不包含凭证、设置存储或图片二进制。
- 三级标题与其所属内容使用同一水平内缩，避免标题和控件形成错位层级。
- 自定义 API 面板保持单一设置流：基础区只保留接口地址、认证、模型、音色／参考音频和响应格式；速率／音调／音量字段、固定 JSON 与额外请求头收进“高级请求设置”。字段名与响应音频字段支持点号路径（如 `input.text`、`data.audio`），留空的可选映射不发送；旧配置归入“自定义 JSON”并保留原值。

### 样式可视化编辑

四版共用原生导航和属性字段。目录只展开；可编辑父层的选择与展开分别操作；选择子层时展开祖先，不强制展开选中的父层。公共入口返回明确主区，置顶和展开详情保持独立作用范围。混合值不显示假定数值，没有匹配的样例不生成默认覆盖；`auto`、`normal` 等来源默认值允许主动设置数值，复杂表达式保留 CSS 控制状态。静态和动态不显示点选轮廓、不临时显露隐藏内容；进入基础或高级编辑清除点选临时状态。

### 样式同步预览

右侧样式预览是唯一操作入口。“打开预览页”复用软件独立窗口，“复制预览链接”复制当前服务端口的固定 `/preview`。切换主题、目标、静态／点选／动态以及未保存草稿均沿用同一地址。网页只显示内容，画布透明，事件保留各模式配色。迟到或重连直接接续当前画面；关闭接收端不改变播放。离开样式后清空旧内容；断连显示重连提示。OBS 配置的右侧预览复用“打开预览页”和“复制预览链接”，同样使用固定 /preview；正式 OBS 地址继续使用已保存配置。数据源放在明暗之后，窗口固定为 OBS，不改写编辑页的预览窗口偏好。

OBS 样例按所选格式复用对应编辑器的素材、随机生成机制和显示容器；接收端消费源端发布的同一画面，不另起生成器。实时模式直接消费已保存配置的实际 OBS 输出，不叠加样例或未保存草稿。显示缩放同步到独立窗口和网页。

同步预览沿用源端的主题、事件、选区，软件窗口和网页分别按自身视口重排，隐藏滚动条但保留滚动。主题明确设置的固定 CSS 尺寸保持原值。软件窗口跟随辅助背景，网页画布始终透明，事件卡片保留各模式配色。

### 主题保存与资源

保存主题与更新输出分别反馈。文件已保存而部分输出更新失败时保留“重试更新”；继续编辑或下一次保存失败不取消此前可重试的保存版本。重试只更新仍引用该版本的失败目标，不覆盖新草稿。

主题资源随主题保存、导入和导出；主题库、编辑预览及正式输出使用同一资源内容。不同草稿的同名资源互不覆盖。主题库缩略图中的字体只用于对应卡片，不改变现场字体。

## 主题信息

内置主题名称、作者和版本以纯文字展示，信息面板只保留关闭，不提供输入框、保存或另存为。另存主题只使用编辑页顶部入口。自定义主题可编辑并保存。作者只保留一个字段；缺失信息显示未标注。来源日期统一按本地YYYY-MM-DD HH:mm展示，只有日期保留日期，没有时区则注明；悬停可查看来源原值。来源时间与导入、本地修改时间分别记录。

样式编辑预览直接展示完整样式，不提供现场、弹幕窗、收益窗和 OBS 目标切换。默认静态和浅色；静态使用真实事件编辑而来的案例，点选使用说明性案例，动态控制紧邻展示模式，整组换行。背景、窗口宽度数值和明暗常显；宽度输入与右侧工作台联动，拖动窗口同步数值，预览内容与背景铺满可用区域。事件筛选支持单类、多类和恢复全部。信息流排列与对齐跟随软件设置，固定案例从对齐的一端开始阅读，动态跟随最新消息；完整案例不强制开启正在编辑的部件。设置与预览共用一个工作台宽度。

### 共享设置与编辑布局

共享输出容量、事件定时消失与合并相同弹幕统一位于“设置 → 事件显示 → 副窗口与 OBS”，搜索到达同一入口；恢复本分类默认只恢复该分类拥有的设置。副窗口明暗位于副窗口设置，默认跟随软件。回看日期始终保留开始／结束可见标签。快捷菜单排序既有拖动方式保留，行获得焦点后可用上下方向键调整。

编辑器页头的“应用”统一更新全部既有引用，预览控制不改变正式输出。高级编辑的基础 CSS 只读，素材操作与层操作保持紧凑；外部 HTML 与 LAPLACE 场景复用现有表单尺寸和输入边界。浮层由共享机制处理关闭、组合输入、Tab 循环和返回触发焦点。

### 样式工作区一致性

- 用户名打码仅改变副窗口、OBS 及其目标预览的已有姓名：首字加三个半角星号；空姓名保持空，不产生回复或改写原始事件。现场与回看不变。
- 可视化编辑初始选公共事件容器。导航、事件范围、身份与预览点选共用有效选择；失效部件回到当前范围公共容器，合法范围保留。中间标题、路径和左侧唯一选中项一致。
- 恢复默认经确认更新当前草稿，应用后才更新仍引用该主题的输出；分项恢复保留其他草稿内容。默认文件、主题 ID、绑定、缩放、房间与明暗不变。发布失败保留对应重试入口。
- 内置主题不可删除；管理混选只确认并删除自定义主题。被使用的主题须先更换引用。取消确认无副作用，删除成功才移出列表。

## 原生事件活动状态

红包与天选开始行显示可靠的活动进度，归零进入等待开奖，收到结果后进入已开奖。开奖状态属于共用原生语义节点，不限于内置默认主题。普通行保留，副窗口与OBS置顶结束；事件筛选不丢弃对应控制事实。计时只更新局部状态，不改变各页面阅读位置或重播旧行。


### 原生实时事件排版

默认不使用左侧类型竖线或专用缩进。用户资料行与事件标题、金额分开显隐；红包奖励、口令与天选条件独立分组。开奖结果使用类别标题和真实人数／奖品，不以首位中奖者代替类别。

活动右图相对整卡居中，状态在尾侧局部避让；空间不足时状态进入可见独立行。布局测量使用未缩放尺寸，关闭状态、主图或头像时释放各自占位。开奖保持正文和媒体不透明，撤回只做灰度处理。新主题默认比例与公共部件定义见[原生事件契约](../development/native-event-style-contract.md)。既有明确调整和固定CSS保持原值。


## 连接列表、软件配色与图片编辑

连接列表包含保存的主播及回看档案补入的主播，不以最近数量截断；直播状态刷新覆盖列表中的房间。连接成功与直播中是两个状态，顶部和下拉列表使用同一房间直播事实，查询失败不当作未开播。移除时明确选择仅移除主播卡或连同回看档案删除；档案删除仍需影响预览与确认。

软件配色和深浅模式独立。樱花粉为初始配色，快捷切换包含自定义；修改自定义色生成对应深浅方案并持久保存。主题自身的身份、价格与背景规则不因此改写。

四个图片编辑面板复用当前模式和正式渲染内容，默认聚焦当前部件，可切换完整事件。调整参数和拉伸预览保留组件状态，不带入点选轮廓。完成设置提交到编辑草稿，取消恢复打开前状态；保存主题与应用输出仍为独立动作。移除图片仅移除当前引用，不删除其他主题的素材。


### 预览筛选与实时状态

全部事件与部分分类是互斥状态，全部事件始终显示可见的选中反馈；选择分类后可追加其他分类，恢复全部后主列表、置顶与共享预览一并恢复。筛选仅影响样例预览。

OBS实时按钮仅在OBS预览标题栏出现。激活时订阅已保存配置的事件，关闭后停止订阅并返回原样例模式；未保存配置时禁用并提示先保存。实时状态不修改输出配置，不覆盖样例筛选与播放选择。
## 设置交互与局部试听

- 配色、明暗、对齐、方向、动画继续由既有设置存储管理；图形示意和试听文案不新增持久化配置。旧内容对齐未定义时保留原布局，不因查看示意而写入顶部或底部。
- 排列示意同时表达内容对齐和最新事件位置。试播只作用于局部样例，沿用五种动画与实际时长；无动画、零时长和减少动效时不播放过渡，离开或改变参数会取消局部动画。
- 语音试听调用现有正式控制器，期间不能重复触发、切换引擎或整体恢复默认。空文本就地提示且不请求服务；失败保留文本，恢复操作能力；控制器返回后显示“试听已结束”，不将中断宣称为成功完成。

### 任务设置与样式属性

- 副窗口明暗、收益窗显示方式、语音队列顺序与优先级、个性播报模式、身份形式和OBS输出明暗保留原值与保存归属，使用共享选择按钮；长列表继续使用原选择器。窗口关闭不妨碍预先配置，锁定操作保持原可用条件。
- 云端连接与记录恢复的反馈分别显示在对应任务内；连接帮助默认收起，身份码显示按钮有明确名称。档案清理、账号同步、采集与OBS端口修改继续使用原影响预览和确认。
- 样式属性的显示/隐藏、常用字重与颜色色样只在明确选择时调用原修改回调；混合值、CSS控制、缺失部件及继承恢复保持原语义。色样选择保留非零透明度；从完全透明选择可见颜色时沿用既有取色规则。
- 回看字号滑动调整与精确输入同步，边界沿用原限制。预览链接只在剪贴板写入成功后显示对勾，失败不显示成功状态；正式OBS地址与未保存草稿继续区分。

高级编辑的复制与清空使用图标按钮，清空为危险色并确认；格式化、素材和导出保留图标与文字。导出 CSS 菜单直接选择导出范围；Ctrl+S 保留草稿，不更新正式主题或输出。另存为不应用输出，原主题已有草稿继续保留。

可视化显示状态使用“显示／隐藏”连体单选，混合值不预选，切回原继承值恢复继承。应用使用对勾与文字，另存为使用保存图标与文字；清空使用危险色垃圾桶图标，保留原确认。

## 副窗口材质与关于

副窗口三种材质共用一套外观设置。旧显式底色、透明度和圆角继续保留；透明材质只隐藏外壳参数，不清除它们。第一次显示等待偏好、原生材质与锁定同步。锁定辅助依据实际原生执行结果，失败提示重新打开窗口；原生模糊失败不循环重试。

主窗口的定位按钮只作用于已开启窗口。收益分窗分别显示自身名称；重复定位重新计时三秒，不改窗口大小、位置或锁定，不抢焦点，不进入事件或OBS浏览器源。透明且未锁定时提供常驻调整辅助，锁定立即取消；之后仍可主动定位。

关于弹窗由设置中的软件信息入口打开。原生dialog负责焦点限制、Escape与关闭后焦点返回，不改变连接、主题草稿或事件阅读位置。减少动态效果时不显示重播操作。

关于页保留角色动画、软件名称、实际版本和“懂你的直播伙伴。”。全部内容居中，徽章换行后的每行也居中。链接区依次展示兼容样式、选定框架组件和作者主页；徽章高24px、圆角6px、图标14px，文字沿用普通控件字号及400字重；分段表面在软件表面色上轻染对应品牌色。“兼容样式”标签与徽章整体垂直居中。使用项目及平台的真实品牌标识，不用通用图标替代；LAPLACE Chat 使用官网产品页的专用图标。兼容样式显示 Blivechat、LAPLACE Chat；框架组件显示 React、Tauri、Tailwind CSS、Radix UI。作者主页链接到用户确认的 B站与爱发电地址，名称未知时使用平台名称。外部链接交给系统浏览器打开，失败时保留链接并提示。许可文件随软件分发，不在此页展开说明。
