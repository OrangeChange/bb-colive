# BB CoLive 界面设计规范

本项目是面向直播现场操作的桌面工具。视觉优先级依次为：现场弹幕的快速阅读、收益类事件的清晰识别、互动与系统信息的低干扰呈现。原生现场事件在连续信息流中按主题呈现：原生默认、浅映卡片和轻语气泡保留各自表面与排版；回看使用独立紧凑排版。设置面板与其他工作台不以卡片堆叠替代信息层次。

> **规范状态（1.0.0）**：本文是 BB CoLive 的视觉与内容表达基线，和 `UX-CONTRACT.md` 一起作为新增或修改界面前的必读参考。代码中的一次性样式不能替代这里的语义规则；如果实现与本文冲突，应先判断是否是有意的局部例外，并同步修正文档或代码。
>
> 当前功能与待验范围见[项目状态](../project-status.md)，功能行为按[功能文档](../README.md#功能文档)维护；本文只定义全局视觉和表达规则。

## 规范化 UI/UX 语言（必须遵循）

### 短选项与开关

共享分段控件统一使用 `ui-type-control` 的14px字号、20px行高，选中态保留600字重。现场布局使用双区、多区两个图标分段选项，悬停显示原布局名称，保留原生单选键盘操作和无障碍名称；设置页的区域布局继续同时显示图标与文字，两处共用同一设置值。双区图标沿用Columns2，多区在同一外框中以左侧两行、右侧三行表示完整分区；两处复用SceneLayoutIcon，图形不随筛选开关改变。收益窗的组合窗口使用钱包图标，分窗显示和分窗小标题使用叠层图标；分窗选项复用侧栏的礼物、引用消息和船图标。

短互斥设置复用SettingsChoiceControl，采用连体分段：共用外框、选项紧贴、内部细分隔线，当前项使用主题底色和字重区分。不显示单选圆点，保留原生互斥选择、方向键和可见焦点。开关状态使用单一开关，长列表保留选择器。身份形式以两列对齐，窄容器转为单列；每项标签与分段控件左对齐、紧邻8px，不以两端对齐拉开距离；不因更换控件改变继承、保存和恢复边界。



### 设置控件与任务分组

语音引擎复用UiSelect下拉选择，保留独立的引擎配置及原切换行为。语音与个性播报共用播报状态布局：状态与标题同行，当前内容独立一行，待播、已丢弃和失败为次级统计；空闲显示等待内容，失败非零时才强调。控制按钮正常宽度靠右，窄宽度另行排列。软件滑块共用浅灰底轨和主题色进度，保留原生滑块的键盘与指针操作。

原生单选输入保留原控件语义和互斥键盘操作，未选中轮廓使用次级灰色，选中轮廓及圆点使用主题色，焦点使用独立外轮廓。主题导入、导出与其他选择面板共用同一外观；分段控件中隐藏的单选输入继续保持隐藏。

通用设置的外观、启动与窗口行为分别成组。配色选项显示对应主色色样，自定义色样使用用户实际选色；深浅模式保留图标与名称。内容对齐通过布局图形表达，最新事件位置独立表达方向，局部排列示意不写入现场或档案。图形选择保留现有搜索定位、选中状态与键盘焦点，按实际空间换行。

语音引擎与专属配置相邻，声音参数独立成组。试听以轻边框和内边距形成独立区域，默认只显示一行输入框与试听按钮，不增加重复标题或常驻说明；结束与错误反馈按需显示。结束反馈使用中性措辞，不将音频中断表示为成功。试听期间暂时禁用引擎切换与整体恢复默认，失败保留文本并允许重试。

少量互斥选项优先直接展示，使用共享连体分段选择呈现当前值；主播、设备、音色、保留期限等长列表继续使用选择器。选项按实际空间换行，不依赖固定列宽。图标辅助分类、方向和操作识别；取色、局部恢复使用具名图标按钮，有歧义的动作保留名称。样式属性按面板实际宽度排布，不限制在固定窄栏；上下文与恢复动作不能相互挤压。

副窗口、档案传输、保留策略、空间清理、云端连接与记录恢复以任务为边界。日期的开始、结束标签与对应输入成组换行。连接帮助按需展开，必需字段持续可见，错误与结果出现在所属任务内。

样式属性沿用正式值、继承与混合状态。从继承值开始编辑后切回原值，恢复原继承关系；原本已存在的自定义值保留。可见性使用“显示／隐藏”连体分段单选，混合值不预选；字重常用值不替代精确输入，非预设字重不默认选中。颜色面板的十二个常用色样单行横向浏览，包含紫色`#7C3AED`。隐藏滚动条，滚轮横移；方向键与Home／End移动焦点并滚入视野，Enter／空格应用颜色；边缘不拦截页面滚动，保留触控板与缩放操作。常用色样复用现有透明度与格式规则；混合值或无法解析的颜色不显示假定选中。复制预览链接成功时在原按钮显示短暂对勾，失败保留错误提示，预览工具布局不因此改变。

### 系统事件文案

原生系统事件与系统提醒共用文案规则。首行说明状态，下一行显示限制范围、警告原因或分区；缺少的操作者、期限和原因不补写。房间禁言开启与解除均使用普通文字及图标颜色，不以颜色区分状态。用户信息仅保留原生用户名和头像，不显示头像框、粉丝牌、身份徽章、荣耀勋章和排名，不保留对应空位。现场开播和下播显示可靠的事件时间，其他系统事件不显示时间列。系统图标使用 SVG。预览管理状态复用独立保存的用户素材，不写入真实记录。

### 产品表达

界面通用图标统一使用 Lucide，标准线宽为 2，尺寸沿用所属控件；新增图标从同一图标库选择。收藏、标记、筛选和置顶在选中时可填充封闭轮廓，开放线条图标通过现有按钮背景表达状态。主播、房管身份图标及官方事件素材保持各自规范。

大航海荣誉使用官方八档透明勋章，复用三个原生主题的水印位置与尺寸，不改变头像、文案和数字的布局。上舰与成就达成动画共用“大航海特效”开关，和礼物特效独立；有可播放资源时，点击对应图标可手动重播。自动播放关闭不禁用手动入口。回看保持独立排版。

danmu-app 是面向直播现场的操作工作台。它的核心不是展示更多装饰，而是让操作者在直播过程中更快看清、判断和操作。所有页面都遵循四个视觉方向：

- **信息流优先**：连续事件流是现场中心，不用大量卡片替代弹幕、礼物和互动列表。
- **工具安静**：筛选、按钮和设置使用克制的表面与边界，把强调色留给当前选择、焦点和少数主要动作。
- **浮层清楚**：下拉、建议、菜单和弹窗必须能看出与触发器的关系，不能裁切、遮挡关键内容或突然变成系统默认浅色样式。
- **设置从容**：设置允许比现场更舒展，但仍使用同一套字号、边框、焦点和语义颜色。

右侧工作台是主窗口的扩展区域，承载设置、辅助信息和编辑器；不要把设置搬到左侧导航，也不要因为主窗口信息更详细而取消弹幕窗或收益窗。外置窗口是只读展示渠道，开启、关闭、锁定、穿透、尺寸和位置由主窗口控制。现场、回看、语音和个性播报是同级主工作台，不通过合并所有事件来代替各自任务。

### 主题入口

主题库在“所有样式”下新建主题时，以双列选项选择原生、BLC 原版、BLC 开放版或 Laplace；具体格式分类下直接新建对应格式。新建和导入面板复用回看导出面板的标题、内容滚动、固定底栏与关闭交互。导入面板中主题文件独占一行，四种 CSS 格式双列排列；仅选择 Laplace 后展开 CSS 文件与远程 URL。文件、名称和代码层在面板内确认，远程 URL 接入加载预览与确认保存流程。

### 统一术语

界面文案、组件名称、诊断摘要和文档使用同一组词。新功能先选择下表中的归属，再决定具体文案；不要为同一对象创造新的近义名称。

| 统一名称 | 指代 | 使用约束 |
| --- | --- | --- |
| **现场** | 当前连接直播间的实时事件工作区 | 不写成“直播页”或“实时页” |
| **回看** | 本地保存的主播档案、场次和历史事件工作区 | 使用“主播档案”“单场”“事件检索”描述层级 |
| **右侧工作台** | 主窗口右侧的可展开扩展区域 | 不称为“左侧设置栏”；设置仍归右侧工作台 |
| **弹幕窗／收益窗** | 独立的外置只读事件窗口 | 不把它们称为主窗口的弹出菜单 |
| **设置** | 全局偏好与窗口行为入口 | 分类名称保持稳定，按分类恢复默认 |
| **样式** | 现场、副窗口和 OBS 的主题、元素显示与外观编辑器 | 不包含筛选、动画、信息流和回看设置 |
| **下拉／选择器** | 固定选项或字体选项控件 | 固定选项使用 `UiSelect`；不要新增原生 `<select>` |
| **组合输入／关键词建议** | 可输入、过滤和选择建议的控件 | 使用 `UiCombobox`，保留最近搜索、键盘和中文输入法语义 |
| **信息流** | 按时间或任务连续排列的事件列表 | 不用“卡片墙”描述现场主体 |
| **事件类型／身份标记** | 事件类别和用户身份的视觉语义 | 类型颜色、身份颜色和显示开关各自归属明确 |
| **系统提醒** | 应用级提示和可展开的提醒列表 | 不与“已连接”“实时记录”等连接状态混用 |

### 用户可见文案

- 标题和按钮只表达对象和动作；辅助说明只保留作用范围、后果或下一步。
- 错误提示必须说明发生了什么，以及用户接下来可以做什么。
- 同一概念全局使用同一名称；不把内部实现名暴露给用户，例如“业务事件”“档案仓库”“source/render”。
- 不重复提示“点击”“回车”等已经由控件形态表达的操作；只有当操作顺序或结果容易误解时才补充说明。
- 备注放在最接近其影响范围的位置。普通设置页删除冗余长备注；确实需要保留的解释使用字段附近的短备注或悬停提示。样式是左侧导航中的独立主工作区，设置页不重复提供入口；编辑器内部保留会影响理解的说明。

### 交互原则

- **保留上下文**：打开设置、筛选、菜单或编辑器不得重建连接、清空事件、重置筛选条件或跳走阅读位置；真正切换查询时只更新对应查询。
- **按任务归属**：一个选项只有一个权威位置；共享声音输出归“设置 → 语音与播报”，事件视觉归“样式”，筛选、动画、信息流与回看行为归软件设置，副窗口筛选只影响副窗口投影。
- **自动弹幕**：“显示自动弹幕”是默认开启的全局显示开关，不改变采集和导出；“合并相同弹幕”归属设置 → 事件显示 → 副窗口与 OBS，自动与普通弹幕均可参与，先过滤再合并；不影响现场历史和回看。
- **手机号验证**：“显示未验证手机号用户弹幕”是默认关闭的全局显示开关，与自动弹幕开关相邻且独立；只过滤明确未验证状态，未知保留，不新增身份徽章。
- **按可用空间布局**：设置控件默认并排；只有当前行实际放不下时才整行换行。分段控件按最长选项保留宽度，换行后整组占满下一行，不用全局固定断点提前堆叠。
- **窄宽样式编辑器**：宽容器保留事件和身份快捷按钮；编辑器容器不超过 700px 时，使用同一选项集合的下拉选择器。属性区保持至少 240px 高；短窗口由编辑内容区滚动，导航与属性区各自保留内部滚动。
- 单场页头保持单行，只呈现面包屑、标题、封面、管理档案和导出数据；直播状态、记录状态和记录质量由列表及时间线提示呈现。长主播名和场次标题截断，操作按钮不换行；窄宽时缩减间距和水平留白，不增加第二行。
- 场次列表“进行中”徽章使用已有 `success` 语义令牌的绿色文字与浅底。
- **浮层可预测**：下拉菜单至少与触发器同宽，可按内容自然扩展并受视口限制；点击外部或 Escape 收回，点击菜单项目不能误关父级筛选。
- 高级筛选共用 `ReviewFilterPopover` 的定位、视口限制与关闭行为，查询条件仍由各入口管理。分类子菜单 ArrowDown/Home 进入首项、ArrowUp/End 进入末项；Escape 回到分类按钮，第一次外部点击关闭子层，第二次关闭父层。普通弹窗返回触发焦点并循环 Tab；导出忙碌时禁止通过 Escape、外部点击或关闭按钮关闭。
- **键盘和输入法等价**：焦点可见，方向键、Home/End、Enter、Escape 与鼠标路径表达同一结果；中文输入法组合期间不能误提交或关闭建议列表。
- **减少动效可用**：动效传达状态和层级，不阻塞操作；`prefers-reduced-motion` 时保留静态状态、焦点和结果反馈，取消不必要的位移和缩放。
- **事件样式克制**：事件类型优先通过排版、身份、图标和细微背景区分。后续事件样式重构不以左侧装饰性彩条作为主要分类手段，也不把所有事件合并成一条难以阅读的总流。

## 规范使用

### 软件配色与控件状态

樱花粉、青瓷绿与自定义配色遵循同一套语义配对。`--accent` 保留主色，用于强调标记与边界；`--accent-solid` 用于实心按钮、选中项和开关轨道，与固定白色的 `--accent-fg` 配对。悬停、按下分别使用 `--accent-solid-hover`、`--accent-solid-active`，不使用整体增亮滤镜。自定义填充色由现有主色收深至适合白字，用户选定的原色和页面背景仍保留。`--accent-text` 用于普通表面和强调浅底上的文字、图标。危险实心操作使用 `--danger-solid` 与白色 `--danger-fg` 配对，悬停使用 `--danger-hover`；危险提示文字继续使用 `--status-danger`。

有意义的普通文字在实际背景上达到 4.5:1；必要图标及状态边界达到 3:1。装饰分隔线和禁用态分别判断，不按普通文字统一加深。半透明表面按合成结果检查；用户事件主题、第三方内容及二维码保留自身用途和规范。

禁用控件不产生激活式悬停反馈。焦点指示立即出现；强制颜色模式使用系统色轮廓。加载、未知、真实零值和未连接分别表达。预览设置只改变预览；编辑自动保留草稿，应用后才更新输出。

### 主题保存与输出设置的呈现

主题编辑自动保留草稿，“应用”为带图标和文字的强调操作，保存主题并刷新全部既有引用；“另存为”为带图标和文字的次级操作。主题信息与样式编辑分离：内置信息只读，个人样式调整可保存。主题卡片以低强调的“已调整”标记表示已保存偏好，不与未保存状态或输出使用中标记混用。

恢复入口按“恢复基础设置”“恢复当前 CSS 层”“恢复主题默认”明确范围，复用现有操作菜单与确认面板；恢复结果先呈现在草稿中，不直接更新运行输出。普通界面不展示基准文件、调整文件等内部存储结构。

OBS 配置的明暗与显示缩放同组排布，使用现有 UiSelect 和字段样式，按容器宽度换行。复制与浏览器打开沿用已有地址操作区，参数覆盖规则放在按需展开的说明中，不新增常驻专家面板。预览明暗仍在预览工具栏，不与输出配置共用可变状态。行为优先级与保存范围以 UX-CONTRACT.md 的“主题调整与 OBS 输出契约”为准。

新增界面复用现有语义令牌与控件，交互归属以 UX-CONTRACT.md 为准。阶段测试、组件验证和待验范围保留在本地历史验收记录，不在视觉规范中重复维护版本进度。

共享事件行的公共结构、部件与样式参数由[原生事件 DOM 与样式契约](../development/native-event-style-contract.md)维护；本篇继续定义全局视觉、控件与默认布局。

## 默认窗口

主窗口默认尺寸为 **960×720px（4:3）**。扣除左右各64px的导航/工作台收起轨道后，现场区域默认约832px；右侧工作台展开时，普通小窗口向右扩宽336px，右侧工作台总宽为400px（包含边距），现场内容不被额外压缩。弹幕窗和收益窗使用各自的 **360×360px** 默认尺寸，尺寸单位不根据 DPI 额外换算；恢复默认时距当前工作区右侧10px，弹幕窗距顶部10px，收益窗紧贴弹幕窗下方。

## 字体与字号

收益窗口默认组合显示。设置 → 副窗口 → 收益窗选择分窗显示后，原按钮的横向展开栏容纳礼物、醒目留言、大航海 SVG 子按钮和共享锁定；总关时仍可展开选择子窗，锁定暂不可用。三窗复用相同事件行、固定卡片和窗口表面。首次与恢复布局避让弹幕窗实际或保存位置，优先左侧、必要时右侧，按礼物→醒目留言→大航海竖排，宽300px、高分别240／200／160px，窗间8px、工作区边距10px。空间不足时收缩至宽240px、高160／160／120px；弹幕窗默认360×360px不变。之后各窗独立移动缩放，不持续排列。

正文使用自带的 MiSans 字体链；时间、数量、价格和排名使用 MiSans；代码编辑器采用 Monaco 自身的平台默认字体方案；登录页和空状态标题使用 TsangerYuMo。内置资源包含 MiSans 常规/中等/半粗字重、繁体字形层和 MiSans L3 回退层，目标覆盖常用及偏僻中文、繁体中文、日语和英语；字符仍可继续回退到系统字体。界面字号通过 `src/App.css` 中的 `ui-type-*` 语义类使用，不在组件中继续新增零散的像素字号。每个主题只保存一个基准字号，范围为14–24px、默认16px；可视化控件调整的正文、元信息、徽标、头像、图标、表情和间距按相对基准关系保存，避免嵌套 `em` 累乘。现场、副窗口和每个 OBS 配置分别保存显示缩放，默认100%；缩放只作用于事件内容，不改变软件控件和窗口几何，更换主题时继续保留。回看使用独立的紧凑事件样式，不参与主题或目标缩放。

| 语义角色 | 字号 / 行高 | 使用范围 |
| --- | --- | --- |
| `ui-type-display` | 24px / 32px | 登录标题、空状态标题 |
| `ui-type-page-title` | 16px / 24px | 页面级标题 |
| `ui-type-section-title` | 14px / 20px | 区域标题、连接卡片、重要数值 |
| `ui-type-event` | 16px / 20px | 通用事件字号令牌；实际主题按底座及局部设置覆盖 |
| `ui-type-review-event` | 13px / 20px | 既有紧凑令牌；当前回看事件由独立样式设置覆盖，默认14px |
| `ui-type-control` | 14px / 20px | 按钮、输入框、普通提示、事件次级内容 |
| `ui-type-meta` | 14px / 20px | 用户名、时间、事件数量、状态、粉丝牌 |
| `ui-type-overview-value` | 14px / 20px | 底栏直播间概览的数值 |
| `ui-type-micro` | 12px / 16px | 徽章、角标、删除标记等非主要信息 |

9px不用于界面文字。数字与中文标签使用相同的 MiSans 字体链，需要列对齐时使用 `tabular-nums`。

事件头像尺寸同时控制头像和容器，默认24px，范围16–40px。大航海头像框绝对定位、居中外绘为头像的1.2倍：16／24／40px头像对应19.2／28.8／48px框；四周外伸10%，不增加容器占位或边距，开关和加载失败不改变头像与正文位置。事件与观众榜、大航海榜复用共享头像及图片回退，榜单保留自身头像尺寸并服从同一头像框开关；使用当前用户身份与房间里程碑选择框，前三头像可加框，不添加身份徽章。

## 间距与控件尺寸

间距基于4px节奏，优先使用4、8、12、16px：

- 现场列表和副窗口的容器外边距为8px。
- 原生事件的外层留白、内边距和事件间距由主题底座与可视化部件共同决定；间距在背景外，内边距参与行高，不用旧全局密度值覆盖主题。
- 元信息、正文和时间是否分行遵循主题排版；主窗口虚拟列表和副窗口使用事件实际尺寸测量。
- 事件字号与行高沿用各主题基准及继承关系；回看连续排列并独立缩放，不统一强制为20px或两行。
- 底栏固定高度为36px；概览标签和数值统一使用14px/20px。底栏始终单行，现场列宽度不超过920px时隐藏版本号，不超过760px时再隐藏事件数，不允许换行撑高主界面。
- 区域标题栏为36px高。
- 现场筛选、搜索、价格输入和通知类工具控件统一为32px高；设置表单使用36px标准控件。标签筛选等低层级微型操作可使用28px紧凑变体，但不改变正文和焦点基线。
- 连接等主要动作按钮为32px高。
- 侧栏轨道按钮为40px见方。
- 小型徽章和数字胶囊与所在文字行垂直居中，不以额外占位改变行间节奏。
- 设置控件默认按内容并排：普通控件列保持 224px 上限，标签保留可换行的最小内容宽度；当当前行的标签、间隙和控件实际放不下时，只有该行转为整行，不再由整个面板的统一断点提前堆叠。分段控件按最长选项保留内容宽度，避免“主播与观众”等较长选项被等分挤压；筛选网格使用 `auto-fit` 按可用宽度决定一列或两列。普通设置行统一使用 40px 行高和 32px 控件高度，开关保留 20px 外观但占完整行高；一级标题线到首行控件保留 10px，二级标题线到内容保留 8px，三级分组线到内容也保留 8px。设置面板以容器宽度而不是屏幕截图像素判断可用空间。
- 主窗口通用动效使用统一节奏：控件状态反馈为 `120ms`，标准状态过渡为 `180ms`，菜单、提示和上下文浮层进入为 `160ms`；更多筛选面板使用同一套浮层进入反馈，模态弹窗的遮罩淡入、内容面板轻微上移缩放；筛选上下文只做一次轻微淡入上移。右侧工作台在小窗口中的原生尺寸补偿与内容进入使用 `240ms` 节奏，展开和收起均连续变化，避免窗口先跳变再显示内容。事件行进入／退出动画由“设置 → 事件显示 → 事件动画”控制，减少动效时取消这些通用位移动画并保留静态层级。

## 布局约束

- 主区域一级工作台包括现场、回看、语音、个性播报和样式；页面切换只改变可见性，不重建连接、停止正式播报或丢弃样式草稿。
- “设置 → 语音与播报 → 声音输出”是收听范围、主播设备和观众设备的唯一界面归属；这三项配置同时作用于语音与个性播报，页面自身不重复呈现。设备选择中的“跟随系统默认设备”在每次播放时读取当前系统默认输出，手动选择设备则保持固定。
- 现场主区域支持双区和多区，事件列表必须保持 `min-width: 0` 和 `min-height: 0`，避免长文本把分区撑开。
- 工具栏允许换行，但新增控件不能依赖固定宽度挤压事件区域。
- 回看按主播档案 → 单场档案组织，保持与现场一致的一级/二级分类和事件语义，但使用独立的紧凑事件行：头像、元信息和正文按可用宽度排列，正文空间不足时自然换行，真实事件时间右对齐；菜单高光可覆盖时间区域。回看复用连接栏，并提供“查看当前主播”“查看当前场次”快捷入口；总览页使用紧凑单行“主播档案”标题，不再额外堆叠“回看”大标题；主播档案页使用单行工具栏，返回和管理档案均为带 SVG 图标的按钮。首次进入是否定位当前主播由设置控制，之后用户浏览的回看路由和查询位置在一级工作台之间切换时保持，不自动跟随现场连接变化。主播与场次页面提供返回所有主播档案馆的面包屑；直播结束后仍可打开对应主播档案和已归档场次。主播卡的“直播中”状态使用当前主题色、圆点、2px 水波边框和主题色外发光，非直播状态不播放动画，并遵循减少动效设置。回看默认按新到旧显示，支持按旧到新切换、单场或主播历史检索、回看自身筛选、礼物合并、收藏状态和阅读位置恢复；现场分类开关、仅大航海进房和实时礼物阈值不投影到回看。排序方向按回看范围持久化；标记不进入档案。现场事件行调整不自动改变回看专属字号和时间排版。
- 主播档案内用“场次／事件检索”分段按钮明确区分两类任务。场次模式只筛场次元数据（标题、开播时间、生命周期、质量、收藏），事件模式只筛档案事件（关键词、分类、收藏、事件发生时间、用户与礼物条件）；两套条件按主播记忆，排序偏好按模式跨主播记忆。模式切换只换内容和查询，不清空另一模式的条件或结果。两种筛选模式都使用与单场时间线相同的筛选框架，并随主播页自然滚动自动收起／展开；管理档案不参与此滚动行为。事件命中按场次连续分组，显示质量、命中数和最多三条摘要，使用分隔线而非堆叠大卡片；分页继续追加。摘要行动将用户带到稳定事件键对应的单场时间线，并使用一次性目标定位，不覆盖已保存的阅读锚点。小窗口下工具行自然换行，输入框保留可用宽度，更多条件以筛选框下沿为锚点浮动，并在视口剩余空间内独立滚动，不拉长结果列表或翻到导航上方。
- 弹幕窗和收益窗复用统一的事件窗口组件，外壳提供玻璃、纯色和透明三种材质，保留8px内容边距。窗口外观与弹幕内容的明暗分别设置，均默认跟随软件，也可分别固定浅色或深色；自动表面颜色随窗口明暗变化，自定义值保持不变。玻璃使用整窗原生模糊、薄着色和细高光，纯色不启用模糊或高光，透明移除外壳并保留事件主题。透明未锁定时提供双层细边框与短窗名，锁定后移除；主动定位显示三秒，不改变几何与锁定。
- 置顶栏在展示区域顶部或底部采用无描边单行紧凑卡片，超宽裁切，复用事件头像、金额和末尾图标；盲盒保留盈亏，天选显示“天选”。头像不超过文字字号，礼物图与身份图使用文字字号；默认内边距上下2px、左右4px，内部间距4px、卡片间距3px，置顶栏到容器边缘及相邻事件流均为4px。有头像框时为外伸部分保留横向占位，确保可见间距一致。卡片没有姓名、正文、可见倒计时或交互入口，复用区域颜色与公共参数，custom层可覆盖；普通事件流独立滚动。参数映射见[样式契约](../development/native-event-style-contract.md#置顶栏)，设置唯一归属及默认值见[副窗口置顶栏](../features/auxiliary-windows.md#置顶栏)。
- 所有控件必须保留键盘焦点样式，并在深浅色主题下使用语义颜色。
- 样式编辑器的元素显示组并列放置头像、头像框、大航海、房管、主播、粉丝牌、榜单排名、荣耀等级和礼物图片；图标／文字控件保持相同样式。榜单排名位于用户名前，身份图标紧凑排列；数据归属和图片选择规则见[事件显示](../features/event-display.md#用户身份与元信息)。
- “样式”集中承载主题基准字号、部件尺寸关系、字体方案、字重、文字描边、事件内边距、事件间距、元素显隐和颜色；现场、副窗口和 OBS 的显示缩放归各自目标绑定，不写入主题包。“设置 → 事件显示”承载信息流、收藏行为和事件动画；“设置 → 事件筛选”承载自动弹幕、手机号验证、进房及礼物条件；回看大表情尺寸归“设置 → 回看”。主题仅应用到现场、副窗口和 OBS，不改变回看。身份颜色继续控制用户名、身份正文和描边；事件类型颜色只覆盖正文和背景。字体、调色、描边和动画参数沿用现有控件与默认值，动画不写入主题文件。
- 事件类型筛选保留在现场工具栏；全局价格与显示策略归设置中的事件筛选，具体范围见[事件显示](../features/event-display.md#礼物与金额)。
- 礼物数值控件复用普通数字输入，不另创价格样式；阈值、步进和金额口径见[事件显示](../features/event-display.md#礼物与金额)。
- “事件显示 → 信息流行为”提供“顶部追加／底部追加”；顶部追加的新事件位于顶部，信息流尚未溢出容器时首条事件从底部开始显示，溢出后跟随顶部向下阅读；底部追加从底部开始跟随并向上阅读。该设置同步主窗口现场、弹幕窗和收益窗，回看不受影响。“事件筛选 → 事件显示策略”中的“只显示大航海进房”只过滤普通进房事件，不过滤其他互动和大航海事件。
- “副窗口 → 窗口外观”共享材质、窗口明暗、表面颜色和圆角：玻璃着色默认18%，纯色不透明度默认100%，两者分别保存，圆角默认12px。透明不绘制外壳。弹幕内容明暗独立设置。定时消失默认关闭、默认10秒，只清理副窗口缓存，不影响主窗口、日志和原始事件；到期事件先播放退出过渡，再移除。颜色编辑继续使用RGBA／HSLA调色器，弹层根据空间翻转。
- 合并弹幕的 ×N 使用独立圆角胶囊，与礼物数量／金额区分；合并范围与默认值见[副窗口显示策略](../features/auxiliary-windows.md#显示策略)。
- 置顶栏卡片各类别共用文字基线和媒体居中规则，不因盲盒盈亏拉高同栏卡片。金额、盈亏与天选文字为区域字号的87.5%，行高为区域字号的1.25倍。进入及退出按栏位置向内滑入、向外滑出200ms；减少动态效果时即时切换，切房不保留旧房动画。具体参数见[置顶栏契约](../development/native-event-style-contract.md#置顶栏)。
- 语音过滤选项与其他播报控件共用设置层级，行为及数据边界见[语音与个性播报](../features/voice-and-broadcast.md)。
- “副窗口 → 弹幕窗 → 事件筛选”保留弹幕与互动总开关，大类跟随现场；细项由主题控制，不复制现场的细项、搜索或用户筛选。收益窗按自身类别采用相同原则；OBS 独立读取主题大类和细项。
- 设置面板层级固定为：一级为分类标题，使用16px较高字号和恢复按钮；分类按通用、事件显示、事件筛选、现场、回看、副窗口、事件交互、语音与播报、其他和关于组织；其中回看负责进入档案的默认范围，事件交互负责事件快捷菜单、用户昵称及朗读昵称开关，语音与播报只负责共享声音输出。二级为功能分组，使用14px中等字重和较大的上方留白；三级为功能子组，使用12px次级文字，与控件内容左侧对齐并用低对比度细线提示分组，不使用圆点。具体开关、输入和分段控件不再使用标题级背景，避免与二级／三级标题混淆。顶部分类导航、查找设置、字体选择、颜色触发器和互动筛选共用统一的圆角矩形外框、边框、背景、焦点和主题色反馈；分类导航保留鼠标滚轮和方向键切换，查找设置按名称或关键词定位到具体设置项并短暂高亮。副窗口的弹幕／互动筛选使用紧凑的两列筛选行，窄面板自动堆叠，一级状态显示“显示／隐藏”，互动的二级筛选通过独立展开按钮打开，激活填充覆盖整行；一级关闭不清空二级选择。固定选项和字体使用 `UiSelect`，关键词建议使用 `UiCombobox`，语音设备继续使用 `SettingsListSelect` 的自绘列表以保留动态设备与不可用设备提示；所有菜单都使用 portal、统一的焦点和选中态，避免原生弹层在不同 Windows/WebView2 环境下出现宽度、位置和对比度差异。
- 启动行为的两个开关保持独立设置行；默认值与启动顺序见[连接与登录](../features/connection-and-login.md)。
- “其他设置 → 窗口布局”提供恢复主窗口、弹幕窗和收益窗默认几何的操作：主窗口960×720，右侧工作台默认400px；弹幕窗与组合收益窗360×360，按工作区右上角10px边距上下堆叠。分窗恢复紧凑收益列并避让弹幕窗，尺寸与位置规则见[副窗口布局](../features/auxiliary-windows.md#布局)。恢复主窗口同时恢复工作台宽度；恢复只改窗口几何，不关闭或解锁副窗口，不清空连接、事件、筛选和日志。
- 样式从左侧导航进入独立主工作区，设置页不提供第二入口。样式首页显示现场与副窗口当前主题，并以卡片统一管理内置主题和自定义主题；分类栏同时保留原生、BLC 原版、BLC 开放版和 Laplace 的明确边界，四种分类均已接入，按各自真实能力显示编辑项。进入主题后，中央区域按“基础设置、可视化编辑、高级编辑”组织同一套 `NativeThemeEditor`，既有右侧工作台展开为样式预览，不另建页面侧栏或第二条滚动区域。预览展示样式支持的完整案例与置顶栏，不按输出窗口分割；默认静态，使用真实事件编辑而来的案例，点选使用说明性案例并支持选择语义部件，动态支持播放、暂停、重播和速度。排列与对齐跟随软件信息流设置；固定案例从对齐的一端开始阅读，动态跟随最新消息。事件筛选支持单类、多类及恢复全部。背景、模拟 OBS 的像素宽度和浅深切换直接可见，明暗默认浅色；独立预览及复制链接使用带提示的图标入口。完整案例不覆盖主题中正在编辑的部件显示属性。预览背景和样例范围只影响预览，不修改保存偏好。事件动画仍归设置。主题属性编辑不改变窗口几何、不重建连接、不清空事件。
- 内置与自定义原生主题使用同一编辑器和预览链路。可视化编辑左侧按语义部件导航，右侧只显示当前部件和形态适用的属性；通用、浅色、深色是独立编辑层，直接修改建立当前层覆盖，恢复继承删除该覆盖。可视化 CSS 可直接编辑，受支持的选择器和属性双向同步到控件；控件只局部更新目标声明，未知规则、表达式、单位、注释和顺序保持不变。无效草稿保留在编辑器中，预览继续使用最近有效结果。
- 高级编辑统一使用按需加载的 Monaco Editor：查找替换、跳转、格式化、注释、补全、折叠、错误定位、全选、剪贴板以及撤销重做由编辑器命令和快捷键提供，不在编辑器外重复放置查找、跳转或撤销重做按钮。代码正文保持14px字号和20px行高，字体采用 Monaco 自身的平台默认方案，不设置 fontFamily 覆盖。可视化 CSS 与自定义 CSS 分别保留文档、选区、滚动位置和编辑历史；切换编辑层或预览状态不丢失草稿。格式化只由明确动作触发且可撤销，失败时保留原文并定位错误。
- 预览背景使用同一个颜色入口切换透明棋盘或纯色，并支持透明度、精确颜色输入和 WebView2 能力可用时的系统取色器。该背景只用于软件预览对照；固定网页和主题输出保持透明，现场、副窗口和 OBS 不继承辅助背景。
- 每个包含可修改选项的设置分类都提供“恢复默认”，且只恢复本分类内的全部选项；新增选项必须同时纳入所属分类的默认值和重置逻辑。“其他设置”的“恢复设置页默认”作为设置页全部设置的总恢复入口，并包含窗口几何恢复。
- 语音面板恢复默认只作用于 TTS 配置，个性播报面板恢复默认只作用于提示音配置，设置 → 事件交互恢复默认只作用于事件快捷菜单和用户昵称，设置 → 语音与播报恢复默认只作用于声音输出；各分类互不覆盖对方状态。
- 语音与个性播报都是主区域一级工作台；侧栏入口使用同一套悬停／键盘展开条，入口按钮切换面板，展开后的状态按钮只切换对应播报开关，两个开关互不影响。
- 现场事件行右缘提供统一的更多菜单：悬停或键盘聚焦时以右缘渐变 glow 提示，菜单使用 portal 浮层，不改变信息流行高；动作顺序固定为“筛选该用户、语音播报、添加昵称、打开用户主页、收藏事件、标记事件”。菜单显示相对时间和实际发送时间，并支持 Escape 与点击外部收回。回看事件复用筛选、语音、昵称、主页和收藏等可安全复用的动作，但不提供现场标记。
- 用户昵称属于“设置 → 事件交互”的唯一数据源；保存后同时替换现场事件显示和 TTS 中的用户名，按 UID 匹配，原始事件和按原用户名筛选仍保持不变。“朗读昵称/用户名”关闭时只省略 TTS 用户名字段，不影响现场显示。
- 收藏和标记使用独立状态图标，不用同一种高亮表达两者；交互见[收藏](../features/favorites.md)与[现场事件流](../features/live-feed.md)。
- 回看管理使用明确的影响预览与确认弹窗，资源占位保持固定尺寸；保存、保留和传输规则见[回看与档案](../features/review-archive.md)。
- 档案管理按范围组织导入、导出和清理，破坏性确认明确显示影响与不可恢复后果；功能范围见[回看管理](../features/review-archive.md#写入管理与传输)。
- 回看删除保护只依据记录状态：记录中、重连中的场次不可选择或删除，已停止场次按预览和二次确认清理；直播状态未知不构成永久保护。直播状态、记录状态、记录质量共用三维文案，直播状态为主，其余为辅助。黄色合并明确缺口，灰色说明停止、标题回退和开播身份不足；同一事实不重复，关闭按场次及原因集合隔离，恢复后撤去过期停止提示。
- 主播档案右上角的“从云端恢复”先打开范围与内容选择：范围为全部场次、选择场次或指定时间，内容只提供弹幕和互动事件开关；场次列表由服务器分页读取。设置中的“云端记录服务”统一承载连接、账号、采集房间与数据保留。登录态同步不把 Cookie 或刷新令牌交给 WebView；账号替换、停止采集和数据保留变更使用明确确认。
- 副窗口中的“开启”和“锁定并穿透鼠标”是当前运行状态；该分类恢复默认只恢复窗口显示参数和副窗口显示策略，不强制关闭、打开、锁定或解锁窗口。
- 诊断区并列放置问题标记、两类导出和日志目录入口，导出进度与完成／缺失结果清楚区分；内容、保管和功能接入见[诊断与日志](../features/diagnostics.md)。

## 右侧工作台统一内容壳层

- 顶部展开按钮进入的功能首页与设置页共用同一套内容壳层，不另设第二种面板边框或滚动方案。
- 壳层使用四边12px外边距、1px边框、8px圆角和与主区域一致的背景；标题区固定在顶部，正文从标题下沿开始。
- 正文滚动容器保持完整高度，正文左右留白16px；隐藏WebView2原生滚动条，使用独立视觉滚动轨道，轨道底端避让右下按钮56px并支持拇指拖动。
- 避让只作用于滚动轨道，不缩短正文、不制造未覆盖区域；后续功能只替换壳层内部内容。
- 工作台的界面展开状态与原生窗口几何必须一致：收起为64px轨道、展开默认400px面板。展开后主场景与工作台之间提供12px命中区的垂直分隔带，可拖拽或用方向键调整工作台宽度，范围为320–560px；主场景较窄时动态收紧上限，避免继续挤压现场。宽度保存在当前 WebView 会话中，收起/重开不丢失；恢复主窗口布局时将其恢复为400px。若原生窗口仍保留上一次展开后的宽度，下一次展开复用当前几何，不重复追加336px；原生尺寸未达到目标时不提交错误的收起状态，用户手动调整后的几何继续作为新的基准。
- 主窗口退出时由 Rust 退出链路先显式关闭 `display` 与 `gift` 副窗口，再退出应用；设置为隐藏到托盘时不属于退出，副窗口随进程继续保留。
- 标题栏与托盘退出均先等待导出、档案写入、副窗关闭确认及诊断最终刷盘；未完成时保留异常收尾状态。诊断提示区分本次未完成与历史累计异常，导出使用实际保存路径和最终缺失项。

## 验收范围

字号和空间调整至少检查：默认窗口、窄窗口、宽窗口、双区、多区、深浅色主题、空状态、已连接状态、长用户名、长礼物名、现场两行事件、榜单展开和副窗口事件流。布局变化不得清空现场数据、触发连接重建或改变两种日志的生成方式。

### 样式编辑共享组件

原生及三版兼容编辑器共用 `ThemeEditorHeader`、`ThemeEditorTabs`、`ThemeEditorContent`、`ThemeVisualNavigation`、`ThemeVisualPropertyPanel` 与 `ThemeVisualPropertyField`。导航组件统一目录展开、父层选择、祖先展开及滚入视野；模式只提供真实部件树和能力。属性字段统一颜色、字体、数值、状态与恢复交互。兼容编辑保留各自来源 DOM、单位及比例规则。

## 当前样式同步预览

- 右侧标题栏的“打开独立预览”统一打开软件独立窗口；“复制预览链接”复制唯一 `/preview` 地址。
- 独立窗口和网页接续当前右侧画布、草稿、事件、设计选区和播放进度；显示端不另行生成或播放样例。
- 网页只显示内容，背景透明；不显示工作台工具栏、棋盘格、房间或主题选择。
- OBS设置保留正式地址的复制、打开和保存，不重复提供样式预览入口。当前预览与正式输出分别接收各自状态。

同步预览沿用源端的主题、事件、选区与阅读位置，软件窗口和网页分别按自身视口重排，隐藏滚动条但保留滚动。主题明确设置的固定 CSS 尺寸保持原值。软件窗口跟随辅助背景，网页画布始终透明，事件卡片保留各模式配色。

### 主题保存与资源

保存主题与更新输出分别反馈。文件已保存而部分输出更新失败时保留“重试更新”；继续编辑或下一次保存失败不取消此前可重试的保存版本。重试只更新仍引用该版本的失败目标，不覆盖新草稿。

主题资源随主题保存、导入和导出；主题库、编辑预览及正式输出使用同一资源内容。不同草稿的同名资源互不覆盖。主题库缩略图中的字体只用于对应卡片，不改变现场字体。

## 主题信息

内置主题名称、作者和版本以纯文字展示，信息面板只保留关闭，不提供输入框、保存或另存为。另存主题只使用编辑页顶部入口。自定义主题可编辑并保存。作者只保留一个字段；缺失信息显示未标注。来源日期统一按本地YYYY-MM-DD HH:mm展示，只有日期保留日期，没有时区则注明；悬停可查看来源原值。来源时间与导入、本地修改时间分别记录。

### 样式参数与 OBS 配置

BLC 原版的整体比例与字体比例并排显示，空间不足时再换行。高级编辑中的外部 HTML 使用紧凑操作行；LAPLACE 场景使用有明确边框的输入框，OBS 联动说明折叠展示，不挤占代码编辑器。OBS 服务状态、端口操作与礼物特效分组对齐；开关复用设置页尺寸，不继承普通按钮的高度、内边距和圆角。配置详情中的名称、房间号、主播和地址操作占满可用宽度，主题与缩放并排，长列表文字截断而不产生横向滚动。

### 样式工作区操作与反馈

图片背景、装饰图、图片边框及头像框共用带范围提示、局部效果预览和固定底栏的设置面板；内部确认使用“完成设置”，保存与输出应用仍由样式编辑页负责。大窗口预览与设置并排，窄窗口上下排列。导入图片后直接用于当前对象，文件与已有素材在同一选择行明确区分；更换图片保留布局，移除图片不删除素材。

效果预览默认“当前部件”，可切换“事件效果”；所选对象水平垂直居中，保留真实主题排版、裁切及辅助背景。预览右侧分隔线调整宽度，底边调整高度，也可聚焦后使用方向键调整。预览复用当前样例与既有渲染组件，缩放保持为1；局部聚焦不带入点选框、不移动主页面。更换图片使用图片图标，移除统一称为“移除图片”，比例锁使用连接状态表示。

图片背景先选显示方式，再调整尺寸、图片位置、移动及图片锚点。图片位置使用有明确方位的九宫格，移动与锚点直接展开，不重复加框。装饰图区分随文排列与自由定位，当前定位参照保持可见，高级图层设置可展开。图片边框将原图可拖切线与四边输入放在同一区域，真实效果统一在左侧预览。头像框使用“沿用主题／自定义／不显示”三态，保留自定义参数，不显示单图排序及随文选项。

编辑页不设置应用目标或独立保存按钮，应用更新全部既有引用，无引用时仅保存；另存为独立展示；主题信息与分项恢复放入更多菜单。窄空间按整组换行，标题截断。主题库分类和搜索共用工具栏；格式在左，已调整与使用状态在同一行右对齐。分类搜索与管理条随主题列表滚动固定在顶部；内置主题删除操作给出不可删除的轻提示。管理模式整卡选择，勾选热区至少 36px，支持全选和反选当前结果；普通模式整卡进入编辑，不自动应用。

OBS 详情表单独立滚动，底部保存与删除栏有实体背景，不覆盖字段。操作结果使用主内容区底部高对比胶囊轻提示，以 160ms 淡入淡出区分面板，成功 2.5 秒、失败 6 秒后退出，悬停或聚焦暂停；字段错误仍就近展示。确认恢复和删除继续使用确认对话框。

高级编辑将 CSS 层切换及素材工具置于首行，代码操作与导出置于次行；导出 CSS 菜单直接提供完整、基础与可视化、仅可视化、仅自定义四个动作；复制与清空使用带提示的图标按钮，清空使用危险色并保留确认。兼容版事件区、事件列表和事件容器提供字体、字号、行高、颜色；具体文字部件保留独立覆盖。LAPLACE 事件层使用来源字体、字号与行高变量。其他结构容器提供用户名和正文文字部件的直接入口。文字部件的表面、间距和边框以及图片部件的间距、尺寸和边框遵循原生底座分工。

兼容版属性面板按真实节点提供能力。SC 正文容器与内部文字独立编辑；普通弹幕不提供 SC 专属容器。粉丝牌整体提供文字及盒模型设置，徽章尺寸作用于实际图标，SVG 删除状态按图标编辑。行内文字不提供无效的垂直外边距；不对称间距、边框及圆角显示混合值。BLC 配色固定显示通用，LAPLACE 保留通用、浅色与深色。盲盒专属金额及趋势只作用于盲盒事件。

## 原生实时事件

弹幕头像位于收缩卡片外并顶部对齐；付费、系统与活动内容使用轻边界卡片，事件颜色仅提供低饱和提示。SC表头与正文分区，译文次级显示。弹幕与SC撤回时整行灰化、无删除线，状态紧随正文。大航海购买不显示粉丝牌。

红包与天选的真实图标相对整张卡片垂直居中，活动状态位于右上角；最短卡片也为两者保留互不重叠的空间。活动归零显示等待开奖，收到结果后显示已开奖；不得以归零代替结果。OBS页面根背景始终透明，事件卡片独立跟随深浅模式。


### 原生实时事件排版

默认不使用左侧类型竖线或专用缩进。用户资料行与事件标题、金额分开显隐；红包奖励、口令与天选条件独立分组。开奖结果使用类别标题和真实人数／奖品，不以首位中奖者代替类别。

活动右图相对整卡居中，状态在尾侧局部避让；空间不足时状态进入可见独立行。布局测量使用未缩放尺寸，关闭状态、主图或头像时释放各自占位。开奖保持正文和媒体不透明，撤回只做灰度处理。新主题默认比例与公共部件定义见[原生事件契约](../development/native-event-style-contract.md)。既有明确调整和固定CSS保持原值。

大航海成就：默认与轻量气泡将数字置于“舰队规模突破”之后，继承该行字号并保留数字颜色；官方勋章使用独立可点击元素、完整不透明度。卡片保留右侧大数字、同心圆及半透明勋章。事件卡片可按内容收缩，现场快捷菜单以既有完整事件行作为定位与悬停区域。大航海月份各部分统一700字重。

原生默认的深浅配色作为内置主题基础CSS维护，源文件为 `src/themes/nativeDefaultTheme.css`。默认主题不依赖自定义配色覆盖；公共颜色仅保留三档文字与五种用户身份，其余局部颜色直接定义。共享事件布局和另外两个原生主题的配色独立维护。

原生默认的字号使用主文、辅助、小型标记三档倍率（16px基准对应16／14／12px），普通与强调字重为500／700。价格符号与数值同字号同字重，数量与月份整体加粗；官方身份材料保留内部比例。可视化编辑器的未设置属性继承这一规范。

三个原生主题共用 `--text-name`、`--text-body`、`--text-secondary` 与 `--size-main`、`--size-secondary`、`--size-small`、`--weight-normal`、`--weight-bold` 的命名。主题分别持有自己的配色与布局，身份色沿用公共规则。轻量气泡的普通价格含SC整组使用普通字重，置顶条使用强调字重；卡片保留大价格与成就数字的层级。天选、红包按行继承颜色，系统事件内部文字同色、图标表达语义。

原生系统图标共用默认主题的深浅语义配色，三个主题的直播开始、结束文字和时间统一700字重。默认与轻量气泡的红包、天选开始事件使用首行头像列，正文沿标题文字列向下排列；轻量气泡的说明行统一行高与间距。卡片保留原有活动布局，天选标题及开奖标题与对应正文同色同字重，两个开奖标题与摘要同字号。撤回标记之前使用可折叠空格，换行后不保留行首外边距。

编辑范围始终展开并随页面正常滚动。属性按面板实际宽度排列，内容区不超过720px时为单列，更宽时固定双列，最多两列，列间24px。字体控件256px、数值输入96px，恢复按钮紧邻控件8px；继承状态紧跟标签8px。面板内边距20px、标签到控件8px、属性行间16px。比例锁固定在宽高之间。

连接菜单的房间号与删除图标共用右端区域；同一行悬停500ms后显示删除图标，离开即恢复房间号，键盘焦点直接提供操作。删除确认默认仅移除主播卡，可选择同时删除该主播回看档案；确认前显示场次、事件和收藏范围，沿用记录中保护及档案删除预览。

## 自定义软件配色

软件配色按樱花粉、青瓷绿、自定义排列，左侧快捷切换包含三项。樱花粉用于新配置和恢复默认，已有选择保留。自定义复用统一色板选择一个不透明主色，使用 HEX、RGB、HSL 格式，不显示 A 通道和透明度控件；自动生成深浅两套界面颜色；拖动实时预览，提交保存并同步窗口。背景和三级文字保留克制的中性色层次，交互色保证文字可读。事件语义色、身份色和弹幕主题自身配色独立。

## 软件配色与编辑面板

软件默认樱花粉，另有青瓷绿和自定义；明暗模式独立选择。自定义色使用统一色板的 HEX、RGB、HSL，不提供透明度；事件部件颜色继续支持透明度。软件强调色不替代主题身份色或金额色。

可视化编辑的范围与身份选项直接展开，不增加页内定位栏。字段按可用宽度排列，字体选择器保留合理宽度，不为填满整行无限伸展；“继承主题”靠近对应字段，间距与字号沿用统一控件。窄宽时按整组换行，不能让标签、单位或继承状态脱离所属输入。

图片编辑保留一个效果预览，默认当前部件，可切换事件效果；部件居中，预览尺寸调整不改变事件字号或重建样例。点选框不进入局部预览。宽高比例按钮使用一致位置；边框素材切分线支持拖动与数值输入，不再另放重复的效果示例。


### 预览控制与配色角色

预览背景右侧保留一个明暗切换按钮，图标表示当前状态，提示说明下一步切换。窗口宽度控件仅显示数值及px，位于该行最右侧，悬停提示与可访问名称为“窗口宽度”。事件筛选的“全部事件”有明确选中标记；分类允许单选和多选，恢复全部同步恢复主列表、置顶与共享预览。OBS预览的实时开关位于复制链接旁，激活后显示已保存配置的真实事件，关闭后返回原样例模式。

预览内容与棋盘格或纯色辅助背景铺满右侧窗口可用区域。宽度输入调整右侧工作台，拖动工作台边缘同步更新宽度数值；内容按窗口边缘换行、裁切和滚动。独立窗口保留辅助背景，浏览器链接继续透明。

樱花粉强调基调为#FB7299，白字实心按钮为#D43870；青瓷绿强调基调为#4C9A8D，白字实心按钮为#388174。自定义主色保留原值，实心按钮及强调文字分别生成。成功状态指示使用#16A34A，浅色文字使用#15803D，深色文字使用#4ADE80。

主题草稿自动保留当前文档、代码与素材，重启后恢复；无效 CSS 原文保留，应用和导出前提示修正。恢复默认只更新可撤销草稿，应用才更新输出。范围栏中的事件、用户身份和价格配色各自左对齐，编辑配色与身份优先级使用下拉菜单；属性面板按实际宽度使用单列或双列。

主题编辑页的应用使用对勾、另存为使用保存图标，均保留文字；清空使用垃圾桶图标与危险色。

副窗口样式支持“全部一样”和“分别设置”。分别设置提供弹幕窗及当前收益窗或三个收益分窗的主题和显示缩放，窗口关闭时仍可设置；未单独设置的窗口沿用公共配置，切换模式保留各自配置。当前使用卡片、主题库使用菜单和编辑器应用范围采用同一窗口列表。从当前使用进入编辑器时，应用按钮标明具体窗口；从主题库进入时选择应用位置。同一主题文件仍共享，修改并应用会更新使用该主题的输出。

当前使用以单排紧凑卡片显示窗口图标、窗口名称、当前主题及缩放比例；空间不足时横向滚动，不增加卡片行数，键盘聚焦时使卡片进入可见区域。点击卡片展开主题选择、显示缩放和编辑主题，点击外部或 Escape 收起。副窗口样式模式放在标题右侧，窄宽度时整组换行。

横向卡片滚动按卡片对齐，四边保留焦点轮廓空间；长主题名称省略并提供完整悬停提示。主题库“使用”菜单与当前使用采用相同的窗口名称和图标，勾选标明正在使用的位置，菜单避让窗口边缘，不受主题卡片边界裁切。

所有副窗口使用浮动小窗口图标；当前使用中的主题选项与 OBS 按原生、BLC 原版、BLC 开放版和 LAPLACE 分组，同名主题附带类型以便区分。设置中的收益窗显示方式保留“组合窗口／分窗显示”。语音引擎和队列溢出处理采用144px紧凑下拉框，空间不足时收缩，切换选项保持宽度稳定。

搜索输入统一使用框内放大镜、说明搜索范围的占位文字和有内容时显示的清空按钮，不在框外重复“搜索”标签。现场、主题库和档案检索保持常驻输入；设置保留按需展开的搜索入口。关键词联想框保留建议、历史及原有提交方式，图标与清空操作保持一致。

## CoLive 与关于

标题栏使用20px高的CoLive静态角色，保留danmu-app名称。表情优先依据连接状态，再判断直播状态；图标不替代连接文字。配色沿用软件实际主色，浅色模式电视为主题色、角色为白色，深色对调；非常浅的主色只加深五官，外框和用户配色不变。

关于从设置打开独立弹窗。既有角色动画是唯一主视觉，进入播放一次、点击重播，结束停在母版；减少动态效果时显示静态角色。名称、实际版本和简短介绍依次排列，作者信息位于底部，不增加装饰卡片或未经核实的外部入口。

系统图标采用交接包固定粉白母版，覆盖窗口、可执行文件、任务栏、托盘与安装入口；网页使用同源矢量图标。关于动画实例不随事件更新重建，4.8秒结束保持母版，只有重播重新计时。

### 副窗口玻璃

玻璃表面使用原生实时桌面折射、连续圆角及边缘高光，替换原系统毛玻璃与 CSS 叠层。默认着色18%；自动表面颜色与软件主题共用浅深表面色，自定义表面颜色优先。边缘折射位移为原型的70%，弯折宽度、高光和圆角不变。窗口明暗遵循用户设置，背景明暗仅影响着色密度，不改变所选模式；不额外提高桌面颜色的饱和度或亮度。窗口明暗与弹幕内容明暗独立。材质仍为玻璃、纯色、透明；玻璃背景和边缘由原生着色器统一绘制，WebView保留事件与交互。


### 软件更新

设置“关于”中，品牌图标、名称与当前版本组成完整的可点击入口，名称与版本上下排列，右侧箭头打开既有关于弹窗。下面依次为启动检查开关、自动／国内／国外线路分段选择和更新状态。自动选项直接显示当前线路，不额外重复来源行。多状态品牌图标随检查、下载、就绪和失败切换，外框与身体保持稳定，仅表情交叉淡变。

更新内容直接展示，操作位于底部，下载页链接靠左，当前主要动作靠右。下载进度配合已下载大小、总大小和速度；离开设置不重置任务。就绪时提供“重启并更新”，退出软件前保存记录。独立进度窗口沿用相同字号、配色、品牌图标和按钮，最小化位于右上，失败时右侧提供关闭及重试。错误详情按需展开，安装进度未知时不显示百分比。减少动态效果时停止表情淡变。

更新通知从底栏铃铛上方显示卡片，查看更新跳转关于设置，就绪卡片可直接重启并更新。关闭使用 Lucide X 图标，关闭发现提示不影响下载完成后的就绪提示。独立更新窗口按内容高度适配，不保留固定高度的底部空白。
