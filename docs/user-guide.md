# BB CoLive 使用指南

这份指南介绍软件中的操作入口与常用步骤。首次使用，可以按“连接直播间 → 开启副窗口 → 选择样式”的顺序开始。

## 界面语言与设置搜索

在 **设置 → 通用 → 界面语言** 中选择简体中文、繁體中文、English 或日本語。安装版首次使用采用安装时选择的语言，便携版可在软件内选择；更改后自动保存，已打开的副窗口同步切换，自动更新保留原选择。

设置页右上角的搜索支持四种语言的名称和关键词。例如英文界面中输入“置顶”或“ピン留め”，也能找到置顶栏设置。结果按当前界面语言显示，选择后跳转到相应项目。

界面中的历史日期、云端恢复日期、统计数字和主题日期按当前语言显示，时区仍使用本机设置。英文、日文界面的人民币金额标注为 CNY，不进行汇率换算。事件内部的正文、身份、时间、金额与名单等内容保持原样；播报语言和音色、导出文件的数据格式也不会随界面语言改变。

## 键盘与日期输入

Tab 在控件间移动；选择器和菜单使用方向键浏览、Enter 确认、Escape 取消并返回入口。输入法选字期间，Escape 优先处理输入，不关闭所在面板。选择器的首字母查找只定位候选，确认后才改变选项。

日期字段可直接输入 YYYY-MM-DD，日期时间字段使用 YYYY-MM-DD HH:mm，时间为24小时制和本机时间。将光标放在年、月、日、小时或分钟处，用上下方向键调整该段；点击日历或按 Alt+↓ 打开同组日历和时分列。仅日期字段不显示时分列。输入无效日期后离开字段会恢复原值。

## 连接直播间

1. 打开软件，按提示使用 B站扫码登录。
2. 在顶部输入房间号或直播间链接，点击 **连接**。已经连接过的主播也可以从主播下拉列表选择。
3. 顶部显示 **已连接** 后，即可接收该直播间后续发送的事件。已连接不代表主播正在直播。
4. 切换直播间时，从顶部主播列表选择另一位主播。需要停止接收时，点击 **断开**。

如果登录失效，重新扫码登录；如果连接失败，先检查网络和直播间地址，再重试连接。

## 查看现场

**现场** 用于阅读当前直播间的弹幕、互动与付费事件。

- 使用顶部的弹幕、互动、礼物、醒目留言与大航海选项，选择希望查看的内容。
- 双区与多区按钮用于切换现场排列方式。
- 顶部可展开观众榜和大航海榜，底栏显示直播间概览。
- 事件提供播报、收藏、标记等快捷操作；显示哪些操作可在 **设置 → 事件交互** 中调整。

现场筛选只改变当前展示，不会删除已收到的原始记录。回看的筛选独立设置。

## 发送弹幕与查看主播资料

现场标题旁可打开弹幕输入框，支持文字、回复和直播表情。事件菜单的“回复该用户”打开同一个输入框。顶部粉丝牌可展开切换佩戴；表情按账号和当前直播间权限显示。发送失败会保留草稿，结果不明确时先查看直播间，避免重复发送。

点击现场或回看事件中的粉丝牌，可查看对应主播的头像、名称和粉丝数；右侧按钮分别打开个人主页与直播间，头像可点击预览。无法确认对应主播时显示不可用状态。菜单和资料卡限制在事件内容区域内，来源事件滚出后关闭。

## 开启副窗口

使用主窗口侧栏的 **弹幕窗**、**收益窗** 按钮开启或关闭对应窗口。

- 弹幕窗用于单独阅读弹幕与互动。
- 收益窗用于展示礼物、醒目留言与大航海。
- 进入 **设置 → 副窗口**，可调整窗口材质、明暗、事件显示和布局。
- 需要单独摆放三类收益时，将收益窗的显示方式切换为 **分窗显示**。
- 开启 **锁定并穿透鼠标** 后，鼠标操作会穿过副窗口。需要移动或调整时，先在主窗口中解除锁定。

副窗口跟随主程序接收事件，使用期间保持主程序运行。

## 修改样式

进入侧栏的 **样式** 页面。

### 选择主题

1. 在 **当前使用** 中点击现场或副窗口卡片，选择主题。
2. 需要所有副窗口统一外观时，选择 **全部一样**；需要分别配置时，选择 **分别设置**。
3. **显示缩放** 只改变对应位置的事件大小，适合在不同显示器上调整阅读效果。

### 编辑主题

1. 从当前使用卡片或主题库点击 **编辑**。
2. **基础设置** 调整主题支持的事件、信息元素和基准字号。
3. **可视化编辑** 调整颜色、间距、文字和图片等外观；熟悉 CSS 时也可以使用 **高级编辑**。
4. 右侧 **静态／点选／动态** 用于切换预览方式。预览中的事件是内置样例，不是正在收到的直播记录。
5. 修改完成后点击 **应用**，按入口选择更新已有输出或指定位置。

编辑和预览不会自动改变实际展示。同一个主题被多个位置使用时，应用修改会更新这些位置；希望各处互不影响时，先 **另存为** 不同主题。

应用主题不等待远程素材下载；已有缓存会复用，其余字体和图片按需加载。导出完整主题包时会收集全部素材，缺失时提示恢复后重试。

在 **设置 → 事件显示 → 事件动画** 中可调整软件动画。默认与主题动画同时播放；打开 **主题动画优先** 后，已有主题入场动画的 LAPLACE 事件不再叠加软件入场动画。

主题库提供导入与导出，方便备份或分享自己的样式。主题不会改变回看页面的外观；回看通过页面中的 **样式设置** 单独调整。

### 调整图片与文字

可视化编辑中的图片背景、装饰图、图片边框和头像框分别打开专用面板。默认查看当前部件，也可以切换到事件效果；拖动预览边缘调整画布大小，不改变内容的缩放。宽高默认保持比例，可按需解除；完成设置后仍需保存或应用主题。

字体选择器按内容限宽；字重可用数字框以100为步长调整，也可以选择400、500、700预设。范围栏超出宽度时可横向滚动，键盘聚焦的选项会进入可见区域。

## 添加到 OBS

1. 进入 **样式 → OBS 设置**，新建配置。
2. 填写直播间，选择主题、显示缩放和明暗模式，保存配置。
3. 点击 **复制 OBS 地址**。
4. 在 OBS 的来源中添加 **浏览器**，粘贴地址，并按直播画面需要设置来源的宽高和位置。

使用期间保持 BB CoLive 运行。修改配置后保存；主题编辑完成后仍需应用，实际画面才会更新。

## 语音与个性播报

### 朗读直播事件

1. 打开 **语音** 页面，选择语音引擎。
2. 配置对应的音色和参数，先用试听确认声音。
3. 开启语音播报。

Edge 在线与 Windows 系统语音使用各自提供的音色；Fish Audio 或自定义 API 按对应服务要求填写配置。

播报状态区可以暂停、跳过当前内容或清空队列。

### 使用本地提示音

在 **个性播报** 中选择本地音频并设置适用事件，试听后开启。提示音可以独立播放，也可以安排在 TTS 前播放。

音频文件保留在你选择的位置；移动或删除原文件后，需要重新选择。

### 选择输出设备

进入 **设置 → 语音与播报 → 声音输出**，统一设置收听范围、主播设备与观众设备。

如果没有声音，先检查播报是否开启、队列是否暂停，再检查音量、收听范围和输出设备。

## 回看与收藏

打开 **回看**，选择主播，再进入某一场直播。

- 使用时间线浏览记录，或切换到 **事件检索** 查找关键词、用户和礼物。
- 收藏重要事件后，可以添加备注与标签，方便之后查找。
- 回看使用自己的筛选和外观，不跟随现场的分类开关与主题。

回看主要来自本机已经采集的记录。连接直播间不会自动补齐此前未收到的全部历史消息。

## 备份与导出

这两类操作用途不同：

| 目的 | 使用方式 |
| --- | --- |
| 迁移或恢复回看档案，保留收藏、备注和标签 | 使用回看中的档案传输、导出与导入功能 |
| 用表格或其他工具分析记录 | 在主播档案或单场页面选择 **导出数据**，使用 Excel、CSV 或 JSON |
| 备份或分享主题 | 在主题库中导出主题包 |

数据分析导出不等同于完整档案备份。需要还原到软件时，使用档案传输。

## 恢复云端记录

已有 BB EventFetcher 服务地址与身份码时，在 **设置 → 回看 → 云端记录服务** 中连接服务器。连接后可以查看服务器版本、登录账号、采集房间和数据保留设置。

- 通过 **记录恢复** 输入直播间号，可恢复该直播间的全部记录。
- 在主播档案右上角选择 **从云端恢复**，可恢复全部场次、指定场次或与指定时间相交的场次；弹幕和互动事件可分别取消，未选择的内容不会下载。
- 恢复中可以暂停并继续。取消恢复需要确认，会撤销本次任务新增的记录，不影响任务开始前已有的档案。

服务器可使用本地登录态同步或独立扫码登录。同步本地登录态需要有效的刷新令牌；账号不一致时先确认是否替换。停止某房间采集保留云端历史，调整保留期限则先预览再确认。

这项功能需要可用的独立服务；未配置时不会自动获得云端历史记录。当前要求历史恢复 API v2、直播协议 0.1.3 与恢复契约 0.3，已核对服务端源码版本 0.7.15。连接时以服务器实际返回的能力为准，旧版仅有原始分页接口时需先升级服务端。恢复结果可以在本地回看中查阅，可靠的标题、主播资料、结束时间与质量修订也会同步更新。兼容范围见[云端记录恢复](features/cloud-recovery.md)。

## 常见问题

### 数据放在哪里？

安装版的设置、登录状态、档案和日志位于 `%APPDATA%\BB CoLive\`。便携版使用程序旁的 `data/`；主题和自定义素材位于程序旁的 `style/`。

备份或移动便携版时，保留完整目录，包括 `data/`、`style/` 和 `portable.flag`。

### 升级时怎么保留记录？

先退出旧程序并备份数据与主题。便携版在原目录升级时，保留自己的 `data/` 和 `style/`。

从旧版 danmu-app 首次升级至 1.0.0 时，软件会复制旧数据并保留原目录；目标目录已有数据时不覆盖。

### 为什么修改主题后没有变化？

先确认已经点击 **应用**，再检查当前窗口是否使用这个主题。编辑器预览不会自动应用到现场或副窗口。

如果提示文件变化，当前修改会保留在草稿中；选择 **保留我的修改并应用** 可以继续保存。选择 **载入文件中的版本** 会放弃当前未保存修改，操作前会确认。

### 如何反馈问题？

记下出现问题的页面、操作和大致时间。在 **设置 → 诊断与日志** 中生成最近24小时或完整日志包，提供给协助排查的人。

日志包不是回看备份；分享前确认接收对象。

## 更新软件

在 **设置 → 关于** 检查更新，可设置启动时自动检查。自动检查不会自动下载或退出软件。

- 更新线路可选自动、国内或国外；自动按所在地区选择，判断不合适时可手动切换。
- 发现新版本后点击 **下载更新**，下载期间可以取消；无法下载时可前往下载页手动获取。
- 下载完成后点击 **重启并更新**，软件保存状态并退出，由进度窗口完成更新，再自动启动。
- 安装版更新原安装目录，便携版更新原便携目录；记录、配置及自定义主题保留。更新失败时按提示重试。

1.0.0 没有软件内更新入口，首次升级到 1.1.0 需手动安装或更新便携目录。
