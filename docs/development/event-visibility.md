# 各场景事件显示规则

现场完全使用现场事件筛选，忽略主题大类与细项。副窗口使用现场大类、副窗口已有总开关和主题细项，不使用现场细项或主题大类。OBS 完全使用主题大类与细项。搜索、用户筛选和上下文定位只影响现场。原生及兼容样式遵循同一规则，来源支持范围保持不变。

- [x] 统一主题事件开关的场景解析，覆盖兼容渲染决策及来源配置。
- [x] 调整原生生成 CSS、现场虚拟列表、副窗口消息准入与 OBS 偏好。
- [x] 静态、点选、动态和外置预览复用实际场景规则；显示全部部件仍可检查所有样例。
- [x] 主题细项始终可编辑，补充控制范围说明及契约。
- [x] 验证互相矛盾的大类、细项组合，并在实际程序核验现场、副窗口、OBS 与预览。

验收重点：主题关闭互动但开启进房，现场开启互动但关闭进房时，现场不显示进房，副窗口可以显示进房，OBS 不显示互动。现场关闭整个互动大类时，副窗口同步停止互动，OBS 不受影响。

实机核验使用真实直播事件。现场进房关闭时，弹幕窗按主题细项显示进房；现场互动大类关闭时弹幕窗清空互动，开启后继续接收。OBS 在现场互动关闭时仍显示其主题允许的互动。BLC 两版及 LAPLACE 的现场渲染、来源配置和弹幕窗正常。四种模式的静态、点选、动态及外置预览完成相同范围的核验。
