# 图片样式契约

四类主题共用图片背景、装饰图、图片边框和自定义头像框设置，通过各自的部件选择器生成CSS，不新增另一套事件DOM。功能操作见[样式与可视化编辑](../features/themes-and-editor.md)。

| 功能 | 归属与行为 |
| --- | --- |
| 图片背景 | 属于目标部件的背景层，可调整尺寸、对齐、移动、重复及与背景填充的前后关系 |
| 装饰图 | 使用目标部件既有绘制能力；支持排列、定位、锚点、尺寸及层次设置 |
| 图片边框 | 作用于部件边框，提供切分、粗细、边缘显示和数值输入 |
| 自定义头像框 | 跟随头像区域与比例，不替代用户头像内容 |

预览复用真实渲染与既有主题CSS，支持当前部件和当前事件两种范围。选中热区仅用于编辑，不写入主题或成为图片效果的一部分。修改后的样式经现场、副窗口、OBS各自的应用边界生效；回看继续独立。

原生与LAPLACE按基准字号缩放，BLC原版沿用其整体比例；BLC开放版按自身单位生成，不能额外叠加缩放。部件没有独立绘制盒、伪元素已占用或受祖先裁切时，应显示实际限制。背景图不向部件绘制盒外延伸。

图片来源、文件名与目录按[资源命名规则](asset-naming.md)维护，导入导出保留素材引用及CSS对应关系。
