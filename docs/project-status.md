# 项目状态

当前客户端版本 **1.2.0**，档案数据库 schema **9**。支持 Windows 10/11 x64，依赖 WebView2。版本声明见 `package.json`、`src-tauri/tauri.conf.json` 和 `src-tauri/Cargo.toml`。

## 主分支后续开发

弹幕发送已接入现场标题旁的悬浮输入框、事件菜单回复及完整直播表情选择。小表情以图片混排并计算平台长度占用，大表情点击即发送；分类使用图片、支持滚轮横移，并按小表情、大表情与通用长条采用不同尺寸。标题行复用原生粉丝牌，展开可切换佩戴。模拟请求验收已通过；本机正式程序已验证原数据目录、表情读取与图片、分类滚动、三类尺寸、当前佩戴及完整粉丝牌列表。实际发出文字、回复与表情待用户指定测试范围后验证；尚未进入 1.2.0 已发布安装包。方案见[弹幕发送](roadmap/danmaku-sending.md)。

## 1.2.0 界面规范与多语言

宿主界面已接入 shadcn/ui，统一按钮、输入、选择器、分段、菜单及弹窗；事件主题继续使用各自的 DOM 和样式。日期时间支持直接输入与同组日历、时分选择，选择器和弹窗保留键盘焦点与中文／日文输入法操作。可视化编辑范围保留按钮行，参数栏横向访问；图片面板复用主题渲染并支持调整预览尺寸。

简体、繁体、英文和日文界面同步适配，空状态按语言使用仓耳与墨、传趣体或 RocknRoll One。开发流程已纳入用语确认、翻译清单与多语言验收。具体规则见[组件说明](../src/components/shadcn/README.md)、[界面语言适配](development/interface-localization.md)及[视觉规范](specifications/DESIGN.md)。

房间封禁与直播切断分别处理，可靠的解禁时间可独立编辑样式；顶部提醒按事件时序更新，期限到达不推断已解禁。现场切换布局不重复播放既有礼物和大航海特效，已缓存更新包在安装前重新验证。

共享控件遵循原有背景、文字、边框与交互配色层级，设置目录菜单右对齐触发框；现场和设置中的事件细项随界面语言即时切换。安装包、便携包和源码包对应同一发行源码。

## 诊断日志状态

容量达到保留上限显示黄色提醒，实际丢弃记录显示红色；写入异常和待写队列满独立显示。轮换每分钟检查，普通及详细日志均保护最近一天仍在写入的文件，保留容量和期限不变。相关原生检查、界面状态与前端构建已核对，已纳入当前 1.0.0 分发。

## 主播列表持久化

主播列表直接核对实际文件内容；读取或解析失败会返回错误，不按空列表保存。首次使用且文件不存在时允许建立列表，状态没有变化时不重写文件。读取失败、后台保存和重启保留行为已核对，回看档案与列表分别保存。

## 已知限制

- 档案“完整”表示当前记录边界和已知缺口，不保证上游下发或客户端接收到所有事件。诊断不能证明从未收到的消息。
- 礼物价值与可信支付分开；未知金额、缺失身份和缺失中奖头像不能凭展示样例补造。旧档案没有可靠原始资料时保留缺失或默认显示。
- 上游接口可能返回 412；当前已有回退和暂停重试，不能保证上游持续可用，失败不伪造直播状态。
- 兼容主题的远程素材可失效，外部资源许可不等于应用代码许可；具体边界见[兼容主题契约](development/compatible-theme-contract.md)。
- 图片装饰受既有绘制盒、伪元素占用和祖先裁切限制，见[图片样式契约](development/image-style-contract.md)。
- 发布验证不覆盖所有显示器／DPI、音频设备、真实长时间采集或上游未出现的协议分支。阶段记录仅证明明确列出的范围。
