# 收藏

## 入口与编辑

现场与回看共用事件收藏，按稳定事件身份保存，不按 UID 批量收藏。回看首页提供独立“收藏”入口，统一展示普通档案收藏和原档案不可用的历史收藏。

每条收藏支持一条备注和多个标签。设置“收藏时编辑备注和标签”默认关闭：点击切换收藏，长按约 550ms 打开编辑器；开启后新增收藏写入成功即打开编辑器，取消编辑仍保留收藏。现场、回看和收藏页复用同一编辑器。

标签选中有高亮、可取消，可连续添加多个。独立词库支持新增、重命名和删除，标签管理不混入筛选条件。取消收藏同步清理关联，但不会误取消同用户其他消息。

编辑器打开后焦点进入备注，关闭后回到原入口；支持 Escape 取消。中文输入法确认候选词不会提交标签。保存期间备注和标签不可修改，失败后可继续编辑。

## 查找与整理

搜索默认“全部”，涵盖事件信息、备注和标签；可选择用户、粉丝牌、礼物、内容或备注。另有主播、标签和更多筛选中的分类、时间条件。备注和标签只在收藏搜索，不扩展普通回看检索范围。

标签多选默认匹配任一个；选两个以上才提供任一／全部。时间默认按收藏时间，也可选事件时间；自定义起止区间独立成行，不挤在选择器后。存在条件时显示清除条件，排序不被清除。

结果按收藏／事件时间顺序或倒序稳定分页。多选只作用于当前已加载结果，支持全选、批量取消、添加／移除标签和导出分析 JSON。

普通收藏可定位原场次，先清除收藏页条件保证目标可见；历史收藏只读快照并提示原档案不可用，不猜测场次、不提供上下文定位。

收藏结果使用[独立回看样式](review-archive.md#独立样式设置)，不加载现场主题或主题自定义 CSS；样式调整不改动收藏身份、备注和标签。

## 保存与传输

收藏提交完成后刷新明确目标和计数；写入失败不发成功通知，刷新失败明确提示已保存但刷新失败。晚到连击编号不改变原行身份。

普通收藏使用场次持久键，历史收藏使用独立来源 ID 与快照；历史收藏派生搜索列可重建，不改事件原文、收藏时间、备注或标签。完整[档案传输](review-archive.md#写入管理与传输)保留备注和标签，分析 JSON 不用于完整恢复。

## 实现与验收

入口：`ReviewFavoritesPanel.tsx`、`favoriteActions.ts`、`archiveFavorites.ts`、`archiveContentSearch.ts`。

验收默认点击／长按／自动编辑开关、多标签添加与取消、标签重命名删除、搜索备注标签、两种时间口径、自定义区间、多选不自动取消、跨入口状态同步、历史收藏边界。
