# 语音与个性播报

## TTS

支持 Edge 在线、Windows 系统语音、Fish Audio 和自定义 HTTP API。HTTP 预设包含 OpenAI 兼容、GPT-SoVITS、IndexTTS 和自定义 JSON。各引擎／预设独立保存地址、模型、音色、参考音频与请求字段，切换不能串用配置。

正式事件使用统一队列；“跳过当前”取消该事件未完成的合成／播放并丢弃事件，后续迟到音频不能播放。菜单语音播报只进入 TTS，不触发个性播报。回看不自动触发语音，仅显式菜单操作播报。

“屏蔽低价醒目留言”过滤价格为 2 元的 SC；“屏蔽低价大航海”按当前可识别的服务单位“天”过滤。两者默认关闭且只影响 TTS；按天不能证明是大航海红包。

自定义 API 的基础区提供地址、认证、模型、音色／参考音频和响应格式；速率／音调／音量字段、固定 JSON 与额外请求头位于高级设置。字段映射支持点号路径，空的可选映射不发送，旧配置保留为自定义 JSON。

## 个性播报

提示音由用户选择本地文件，不内置、不上传、不复制到程序目录。独立运行时与 TTS 互不等待；“TTS 前播放提示音”时可提前合成，提示音结束且达到间隔后播放该事件 TTS，再处理下一事件。

提示音之间的间隔与提示音到 TTS 的间隔分别设置，后者只在第二种模式生效。试听为独立单槽打断通道，连续试听立即替换，不改变正式队列。

礼物阈值使用[统一显示与金额规则](event-display.md#礼物与金额)，事件昵称与朗读用户名设置见[现场交互](live-feed.md#事件交互)。大表情播报屏蔽缺省为 true，显式 false 保留。

## 输出与页面切换

“设置 → 语音与播报 → 声音输出”同时作用于 TTS 与个性播报，可选主播设备、观众设备或两者。“跟随系统默认设备”每次播放重新解析当前默认输出，不保存固定 ID；手动选择保持固定。

语音和个性播报面板持久挂载，切主页面不重置连接或正式队列。试听和正式事件分别记录诊断。

事件主题与软件配色不改变声音引擎、输出设备或队列。修改外观后的朗读内容仍取事件字段和语音设置，不读取 CSS 伪元素添加的装饰文字。

## 实现与验收

入口：`src/components/VoicePanel.tsx`、`PersonalBroadcastPanel.tsx`、`src/runtime/liveEventDelivery.ts`；音频与语音实现分别在前端语音模块和 `src-tauri/src/`。

验收引擎配置隔离、跳过当前、迟到合成丢弃、两种提示音模式、试听打断、页面切换队列保持、默认／固定设备解析和失败诊断。不把当前调试目录不同造成的设置差异误判为配置未持久化。
