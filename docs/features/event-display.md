# 事件显示

## 样式与场景

原生主题为原生默认、浅映卡片、轻语气泡，共用语义DOM与底座；回看使用独立样式。现场事件类型和细项由现场筛选控制；副窗口大类跟随现场并结合窗口自身开关，子类采用主题细项；OBS使用主题的事件类型和细项。信息元素显隐与外观仍由所用主题控制。对应预览采用相同场景规则。

原生价格梯度默认开启，普通礼物、盲盒和醒目留言可按类型选用。基础档从0元开始，默认后续边界为30、50、100、500、1000、2000元；边界和明暗配色可编辑，档位以稳定标识关联，修改金额不改变自定义颜色的对应关系。盲盒置顶资格按开出礼物价值计算。

“显示未验证手机号用户弹幕”位于设置 → 事件显示 → 其他显示内容，与“显示自动弹幕”相邻，默认关闭。仅隐藏明确未验证手机号用户的弹幕，已验证及未知状态保留；统一影响现场、回看时间线、检索、收藏、弹幕窗和当前设置预览。采集、保存、导出和语音设置不变，礼物及互动等非弹幕事件不受影响。

“显示自动弹幕”默认开启，位于设置的事件显示选项中。关闭后现场、回看时间线、事件检索、收藏及弹幕窗不显示已由原始发送标记识别的自动弹幕；旧记录缺少标记时保持可见。采集、保存、导出与语音设置不受影响。相同弹幕合并独立生效，弹幕窗先过滤再合并；重新开启时恢复缓冲范围内的自动弹幕。

## 共享设置

主题基础设置中的事件类型只控制 OBS，分类细项控制副窗口和 OBS。现场忽略这两组主题开关，完全使用现场筛选。副窗口大类跟随现场，并受副窗口已有的弹幕、互动总开关控制；细项来自所用主题，不跟随现场细项。现场搜索、用户筛选和查看上下文不传给副窗口。OBS 不读取现场和副窗口的事件类型筛选。各模式的预览遵循所选场景，显示全部部件时可检查全部受支持样例。

原生、BLC原版、BLC开放版和Laplace共用软件事件筛选、事件动画与信息流行为；各版保留自身DOM、CSS和模式特色。主题控制其支持的元素与外观，现场、副窗口及OBS按各自绑定应用；回看保留独立显示设置。主题保存一个基准字号，大表情及其他可视化部件按各自相对比例随基准字号缩放。榜单用户身份复用同一大航海组件，前三头像不加身份标记。

样例按真实采集能力提供元信息，不给所有事件强行添加全部字段。弹幕可包含荣耀等级、粉丝牌和榜单排名；互动可包含荣耀等级、粉丝牌和大航海身份；其他事件只展示其实际提供的资料，天选开始不虚构用户。

公共区域、事件类型、用户子树、部件关系与CSS参数统一维护在[原生事件 DOM 与样式契约](../development/native-event-style-contract.md)。

## 用户身份与元信息

| 大航海图标 | `GuardIdentityBadge` 唯一组件；图标模式优先当前房间明确 URL，同房间同 UID 已观测 URL 可补齐；缺失／失败按房间档位及身份选择内置图标，文字模式才显示文字 |
| 房间档位 | 连接请求读取 `getInfoByRoom.data.guard_info.anchor_guard_achieve_level`；已知值 >=10000 为万舰、>=1000 为千舰，均使用加强套系；普通或未知使用基础套系，不按人数或图片文件名推断 |
| 头像框 | “显示头像框”默认开启，按事件用户里程碑与身份使用内置基础／千舰／万舰框；百舰、未知及旧档案缺失里程碑均使用基础框；独立于大航海标记的图文模式和开关，关闭头像同时隐藏框 |
| 荣耀等级 | 总开关默认关闭，显示方式默认图标；已采集等级使用内置 1–80 级图片，文字模式为 `LvN`，超出内置范围显示数字；不依赖 ENTRY_EFFECT 才能渲染 |
| 榜单排名 | 独立开关默认关闭；在用户名前显示 B 站风格“榜 N”；不等于用户等级、荣耀等级、榜单列表序号或大航海身份 |
| 其他信息 | 房管、主播、粉丝牌、头像、礼物图标及事件图标使用独立开关；用户名身份色按真实身份保留 |

原始大航海等级 `1=总督、2=提督、3=舰长` 转为模型 `1=舰长、2=提督、3=总督`，不能直接混用。房间图标套系随已捕获事件用户资料进入档案，回看不请求当前直播间猜历史身份。

当前房间档位晚到时，现场、弹幕窗和礼物窗回刷已有大航海用户，并应用于后续事件。副窗按现有房间与切换序号同步，保留事件身份及停留时间；旧房档位不串入新房，不迁移历史档案。

荣耀等级来源与普通用户等级分开，`DANMU_MSG.info[4][0]` 不是荣耀等级。原始图片 URL 可保留，但当前荣耀渲染由 `wealthMedalAssets.ts` 选择内置资源。旧事件缺少资料不能追溯补造。字段来源与覆盖证据见[协议研究](../research/README.md)。

## 礼物与金额

普通礼物同用户、同礼物、有效连击窗口内合并，优先使用服务端连击标识。可关联的盲盒结果更新同一占位行，无法关联则不强行合并。COMBO_END 等重复摘要不重复展示和统计。

普通礼物正文按“送出”、礼物主图、礼物名称及数量、主价格排列；盲盒来源图与来源文字保持在同一正文范围。可播放的礼物图保留原特效动作。醒目留言已有译文在原文下一行显示，无译文不留空行。

礼物价值与实际支付分开：价值按礼物本身单价与数量，盲盒为开出礼物价值；支付按可信增量相加、可信累计替换。新增数量支付未知时，整行支付未知；免费为零，未知不能写成零。

SEND_GIFT_V2实际携带的礼物块field 7用于支付金额，盲盒不使用开出单价代替支付。普通连击可使用已携带的累计总金额补齐合并行支付，盲盒不套用；字段依据见[礼物金额调查](../research/gift-price-fields-analysis.md)。

全局最低显示金额作用于现场收益区、收益窗、TTS 和个性播报，覆盖礼物、醒目留言和大航海购买，修改后动态生效。单件口径比较单价；累计口径对礼物和大航海购买比较本条事件单价乘数量，醒目留言仍使用事件金额。盲盒使用本体价格，不使用开出价值；红包、天选、大航海进房及金额未知事件不受门槛影响。步进在当前值基础加减 0.5，不强制对齐倍数。回看使用自己的价格筛选，不继承现场门槛。

大航海购买事件使用原生素材中的专属购买图标，由 `GuardPurchaseIcon` 按舰长、提督、总督与房间档位选择，不复用用户身份徽章。用户信息栏不重复购买身份；其他事件及榜单继续使用身份组件。大航海成就使用官方八档勋章，档位为100、666、888、1000、1314、2233、5200、10000；有资源时，购买和成就图标均可手动播放大航海特效。

`GUARD_ACHIEVEMENT_ROOM` 按官方网页的成就提示规则，仅在 `event_type` 为数值1时生成显示事件；其他类型保留原始采集记录，不进入成就列表、去重或特效播放。`GUARD_FAME_GLORY_EVENT` 的月度八档成就独立处理。旧档案不按缺失的类型字段重新判定，也不改写已保存的内容。

购买原报文没有头像时，优先复用当前连接已观测的同UID头像，仍缺失时通过现有用户资料接口补取；失败继续使用默认头像。补取仅作用于新收到的购买事件，不重写历史档案，切房后不投递旧请求结果。

自动弹幕保留原始 `DANMU_MSG.info[0][9]` 为 `danmakuSendType`，数值非零时 `isAutoDanmaku=true`；数值零或缺失不按文字猜测。旧档案缺失标记不补造，显示由“显示自动弹幕”统一控制。

## 中奖名单与天选条件

天选及红包开奖保留首位中奖者、实际已收到人数和奖品摘要。现场和回看时间线可展开已收到的中奖名单；名单最多占240px高度，超出后内部滚动。用户名沿用宿主已有用户筛选；没有筛选回调时显示非交互文字。缺少用户名显示实际UID，UID也缺失时显示“未知用户”。名单显示头像与用户名，头像优先使用原始中奖者资料，缺失时按可取得的资料补齐；不补造身份，不以奖品数量推算人数。旧档案补齐不改动原始日志。

弹幕窗、礼物窗、事件检索、收藏和样例预览保留摘要，不提供名单展开。展开能力由宿主明确启用，与用户筛选回调独立。展开、收起通过现有行高测量更新列表布局。

天选开始保存的资格文案有值时生成条件节点，默认隐藏；自定义样式可显示，具体选择器见[样式契约](../development/native-event-style-contract.md#内容部件)。

## 个性化与资源

事件间距、内边距、字号及配色由所选主题底座与对应部件覆盖共同决定，不使用一个旧全局默认值代表三个原生主题。可从父级继承的属性不在子部件重复声明；用户名身份色、正文色和金额档位配色分别控制。回看使用独立设置。

动画提供无动画、淡入淡出、轻微上移、轻微缩放、横向轻滑，默认淡入淡出 200ms；进入和退出使用同一预设与持续时长。上下箭头步进 50ms，负数归零；到期事件完成退出动画后移除，无动画直接隐藏。

回看表情随独立回看字号和行高缩放：小表情为一行高，大表情限制在两行高范围，长条表情保持宽高比；不读取主题基准字号或可视化编辑参数。回看“显示大表情”只影响独立大表情事件，不影响普通文字、小表情、礼物图片及原档案。

有用户的事件头像缺失或加载失败时使用内置 B 站默认头像；内置图也失败时显示非交互占位。头像URL变化后重新加载，关闭头像开关后不生成头像容器，无用户事件不补头像。头像框失败只隐藏框，保留头像。

礼物主图依次尝试已有webp、gif、icon来源，穷尽后使用内置 Laplace 电池图；盲盒来源图使用各自候选，穷尽后使用内置盲盒原图，开出礼物仍走主图链。内置主图也失败时保留礼物符号，回看有远程来源时保留手动重试；内置盲盒图也失败时省略图片，文字与金额继续显示。表情沿用可用图片来源，失败保留正文或回退文字，回看保留既有表情重试入口；当前没有应用管理的表情图片缓存入口，不专门预缓存或新增缓存机制。大航海图标按身份规则回退。封面规则见[回看与档案](review-archive.md#封面)。字体、布局与控件视觉细节维护在 [DESIGN.md](../specifications/DESIGN.md)。

表情失败回退准确保留原文字，不额外添加方括号；小表情回退保留原占位文本及前后正文，大表情与横幅保留原弹幕文字。软件已有对应图片缓存时复用，没有时维持文字回退，不新增专用缓存或预缓存。

醒目留言已有翻译字段为非空白字符串时，在正文后显示原翻译；没有翻译时省略，不补采或在线翻译。删除状态继续显示正文删除线和“已撤回”标记。大航海时长及陪伴天数保持原文案和单位，特殊时长 `*5天` 显示为 `×5天`。

## 事件预览

样式编辑器可切换现场、弹幕窗、收益窗和 OBS，分别使用真实排版、基准字号、部件相对尺寸和副窗允许类别。默认“当前设置”服从主题中的显隐、身份图标／文字及粉丝牌条件；“全部部件”临时开启样本已有部件，便于观察样式，不修改保存主题。没有匹配类别的样例时显示空态。

预览共用正式事件行和样式配置。静态样例按类型顺序展示，点选为说明式样例，动态按最新静态素材生成事件并支持低频重复、弹幕合并及礼物连击，可暂停／继续；样本中的回复、翻译、横幅、删除状态、时长与奖励只展示已提供字段。

## 实现与验收

主要入口：`EventRow.tsx`、`GuardIdentityBadge.tsx`、`eventDisplaySettings.ts`、`wealthMedalAssets.ts`、`roomGuardProfile.ts`、`giftMerge.ts`；预览使用 `StylePreviewArea.tsx` 与 `stylePreviewContext.ts`，公共样式实现见[契约](../development/native-event-style-contract.md#私有布局与实现)。

验收主／副窗口、回看和榜单的开关及图标／文字一致性；普通／千舰／万舰房间及 URL 失败回退；字段缺失不伪造；样例符合设置；连击与盲盒更新、未知支付及阈值动态生效。


## 信息流行为

设置 → 事件显示中的“内容对齐”只控制短列表整组贴顶部或底部；“最新事件位置”控制事件排序、插入端和回到最新的目标端，两者独立。新配置默认顶部对齐、最新事件在下方。缺少对齐字段的旧配置在显式选择前保持各版原布局，选择后四版统一执行该设置；主题和链接不另存一套行为值。

各页面独立保存阅读位置。滚离最新端后暂停跟随，追加事件不抢走当前阅读锚点；回到最新端或使用“回到最新”后继续跟随。改变内容对齐或最新位置不清空事件；阅读中保持事件锚点，跟随中定位到新的最新端。

容量、定时消失、相同弹幕合并归设置 → 副窗口与OBS，只控制输出事件流，不截断现场会话历史。最低显示金额属于事件筛选，置顶最低金额属于置顶栏，礼物高亮金额只属于Laplace模式特色，默认30元。

## 设置与预览

事件显示恢复默认只恢复本组行为、动画与置顶，不覆盖保存主题、目标绑定和回看外观。事件筛选恢复默认只恢复本组筛选，不改现场左右分类。副窗口与OBS恢复默认只恢复本组容量、寿命、合并、窗口外观和收益窗相关开关。

右侧预览、独立预览窗口和固定网页同步事件与样式，各自滚动。当前设置按所选目标解释筛选和元素；显示全部部件临时放开样例部件，不修改保存主题。静态和点选保留样例，动态执行目标容量和寿命。固定网页背景始终透明，软件预览保留模拟背景；礼物动图不受独立礼物特效开关控制。

## 原生实时活动

红包与天选的可靠开始、截止、服务端时间独立保留；未知截止时间只显示原有时长描述。明确截止优于推导时长，重复开始不延长活动。开始与结果按房间、活动种类和活动ID关联；END结束参与，AWARD确认开奖，用户资格CHECKSTATUS不结束全局活动。结果被隐藏时仍更新已显示开始行的状态。

收到开奖结果后原生普通行显示已开奖，副窗口和OBS置顶退出；兼容样式维持既有事件移除策略。静态与点选使用固定预览时钟，动态与实时输出使用当前时间；各页位置独立。旧档案不补造截止时间。


### 原生实时事件排版

默认不使用左侧类型竖线或专用缩进。用户资料行与事件标题、金额分开显隐；红包奖励、口令与天选条件独立分组。开奖结果使用类别标题和真实人数／奖品，不以首位中奖者代替类别。

活动右图相对整卡居中，状态在尾侧局部避让；空间不足时状态进入可见独立行。布局测量使用未缩放尺寸，关闭状态、主图或头像时释放各自占位。开奖保持正文和媒体不透明，撤回只做灰度处理。新主题默认比例与公共部件定义见[原生事件契约](../development/native-event-style-contract.md)。既有明确调整和固定CSS保持原值。


礼物V2的粉丝牌优先读取发送者资料中的牌，缺少时读取报文独立粉丝牌块。保留其他主播粉丝牌并标明归属，是否显示由粉丝牌设置决定；其他主播粉丝牌不提供当前房间大航海身份或图标。荣耀等级只读取报文已有字段或同连接已有资料。互动V2的点亮状态使用原始字段8，缺失不推定为未点亮。

红包开奖的扩展数组名单从第9项公开资料的 `base.face` 取得中奖者头像；第3项是bag_id，不作为图片地址。对象格式沿用face/avatar；未提供头像时使用公共默认头像。原生和Laplace使用同一公开头像，不读取origin_info中的原始头像。

## 房间封禁提示

房间封禁与直播切断分别记录。封禁原因保留平台原文，解禁时间只使用可靠字段，按北京时间展示完整日期；没有明确期限时不推断为永久封禁。原生主题可单独调整“解禁时间”部件，兼容主题没有对应组件时使用通用系统消息。封禁与警告、切断共用显示和播报分组。字段与顶部状态规则见[原生事件样式契约](../development/native-event-style-contract.md)。
