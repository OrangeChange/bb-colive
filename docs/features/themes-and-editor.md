# 样式与可视化编辑

适用版本：0.4.13。

## 主题与应用

主题库按原生、BLC原版、BLC开放版、Laplace分类，每类默认主题优先，其余遵循来源顺序，Laplace内置先于远程。界面显示31个内置主题；分发另保留旧YT主题文件，共32份。三个原生主题名称为原生默认、浅映卡片、轻语气泡，稳定标识和既有存储目录不随显示名称改变。

现场、副窗口和OBS分别应用主题；回看独立。基础设置管理当前样式支持的事件与信息元素，可视化编辑按事件、身份、部件及深浅范围修改，高级编辑提供可视化CSS和自定义CSS。未知CSS保留，不强行转换成控件。

原生样式按底座 base、主题 default、软件配置 config、用户 CSS custom 的顺序覆盖。主题中普通的 `.event` 规则可以覆盖底座更具体的事件规则，无需添加 `!important`。框架重置保留在较低的 theme 层，工具类位于 utilities，不参与这四层的职责。现场、副窗口、OBS、编辑预览、缩略图和导出保持同一顺序；回看、检索和收藏保持独立外观。

## 颜色与渐变

颜色面板支持HEX、RGBA、HSLA、透明和系统取色。背景填充支持纯色、线性渐变与径向渐变，色点可拖动或输入位置，线性方向提供角度控件。识别到图片背景时显示简短提醒；图片背景独立编辑。

价格梯度的总开关位于基础设置；可视化编辑选择固定配色或金额档位，管理档位使用弹窗。不同主题保留各自渐变、不透明度与排版，颜色档位不把所有主题变成同一种外观。

## 图片编辑

| 功能 | 操作与范围 |
| --- | --- |
| 图片背景 | 添加、更换、移除、排序、隐藏图片层；调整尺寸、比例、铺满、完整显示、平铺和位置 |
| 装饰图 | 选择随文或自由定位，调整方位、移动、图片锚点和层级；保留主题裁切规则 |
| 图片边框 | 拖动整条切分线，或输入上、右、下、左数值；调整粗细、边缘显示、内部填充和向外延伸 |
| 自定义头像框 | 沿用主题、自定义、不显示三种状态；框与头像比例协调，切换状态保留已设参数 |

各类样式只在真实可用的部件开放功能，不额外改写事件DOM。原生和Laplace尺寸可随基准字号缩放；BLC原版结合整体比例，开放版按其来源尺寸规则处理。宽高可锁定比例，位置与图片自身锚点分别控制。

四个面板共用当前主题、样例和渲染组件，默认只预览当前部件，可切换事件效果。部件水平垂直居中，右侧分隔线与底边可调整预览尺寸，调整画布不缩放内容；主预览点选框不进入局部预览。完成提交设置，取消恢复草稿前状态。预览棋盘与画布底色不进入实际输出。

## 样例与点选

静态预览按事件顺序排列；点选采用说明式样例，悬停显示可编辑区域，点击选择部件，父级边缘可选择整体。原生点选分别展示正文混排、通用横条、UP主大表情、房间专属、充电专属与收藏集表情，并覆盖自动弹幕、大航海进房、同身份普通／千舰图标对照。动态预览沿用最新静态素材，只对弹幕、普通礼物和盲盒生成低频重复，支持跨事件重复、弹幕自动合并和礼物连击增长。原生样例的图片保存在本地，静态与动态共用已确认的用户、正文和金额；带平台译文的醒目留言也进入动态候选。连击摘要只有总价和数量时，续击按两者计算单件金额。BLC两版按来源能力展示礼物名与数量，不提供盲盒专属内容。

右侧与外置预览共用样例和显示规则。原生、兼容主题各自保留来源结构，支持的部件以能力表和实际节点为准。

## 保存与资源

主题位于程序旁`style/`。内置基准与个人调整分开保存，保存调整不自动应用到输出；应用先保存，再更新使用该主题的输出及指定目标。恢复默认先进入可撤销草稿，保存后落盘。另存与导出包含当前完整有效内容，不依赖原机调整目录。保存、另存为、导入和导出共用主题文档与素材管理。完整主题包包含需要的素材，资源准备失败时不生成不完整包；删除图片引用不会批量删除素材。存储及发布约束见[构建与发布](../development/build-and-release.md)。

内置和自定义主题均检测编辑期间的文件变化。有未保存修改时保留草稿，并提供“保留我的修改并应用”和“载入文件中的版本”；载入前确认放弃当前草稿。保留修改时按文件最新修订保存，继续检查保存期间的版本冲突。保存失败不更新输出；部分输出更新失败时显示失败目标并提供重试。

## 软件配色

软件配色提供樱花粉、青瓷绿、自定义，默认樱花粉；左侧快捷入口可切换到自定义。自定义主题色复用公共色板，只提供HEX、RGB、HSL，无透明度，由所选颜色生成浅色与深色方案。已有配色选择和自定义色保存在本机。软件配色不覆盖事件主题自行定义的身份色和价格色。

原生可视化属性读取会随预览载入、图片失败占位和名单展开更新。数值输入先保留草稿，提交时限制有效范围；恢复继承时清除对应配置。CSS未改写图片背景时保留隐藏图层和图片编辑参数，图片尺寸与边框的配套声明完整同步。部件与属性的现行边界见[原生事件样式契约](../development/native-event-style-contract.md)和[图片样式契约](../development/image-style-contract.md)。
