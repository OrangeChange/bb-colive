# 现场事件流

## 范围与筛选

现场支持双区／多区，弹幕与互动、礼物、醒目留言、大航海按区域展示。分类“全选／取消全选”调整一级及互动／礼物细分分类，不清除关键词、价格阈值或布局。

现场保留程序本次会话收到的全部事件，不按副窗口或 OBS 的显示容量截断；输出淘汰、到期和分类切换不删除现场历史。

现场过滤不影响档案原始事件。[礼物阈值和金额](event-display.md#礼物与金额)与[回看查询](review-archive.md#时间线与检索)各有明确范围。

## 阅读与定位

信息流行为提供“顶部追加／底部追加”，同步现场和副窗口，不改变回看排列。最新入口随追加方向位于对应一端，箭头方向一致。

查看上下文在有筛选条件时提供：退出文本／用户检索，在原分类信息流中定位单条目标。定位或跳转到标记后停止跟随，新事件不能推走阅读位置；回到最新重新进入跟随。现场定位使用实测行位置并等位置稳定后完成，不恢复旧筛选视图的滚动位置。

标记是每个事件区域最多一个阅读位置，新标记替代该区域旧标记。目标以事件行身份确定，不能把同 UID 的所有事件标记。标记不进入档案，也不与回看标记建立关联。

## 事件交互

现场有有效用户和发送回调时，更多菜单首先提供“回复该用户”，其余动作按“筛选该用户 → 语音播报 → 添加／更改昵称 → 打开用户主页 → 收藏事件 → 标记事件”排列；有筛选时增加“查看上下文”，用户筛选可明确退出。

昵称按 UID 共用，在用户名后括号显示，TTS 是否朗读由对应开关控制。收藏按事件稳定身份保存，不按 UID 收藏全部消息；编辑交互见[收藏](favorites.md)。语音播报只进入 TTS，不触发个性播报。

快捷按钮可从回复、播报、筛选、收藏、标记中选最多三个并拖动排序。收藏和标记状态持续显示，筛选不累积成事件状态。

头像可点击预览。结构化回复的 `@用户名` 可筛选目标，普通文本 `@` 不伪造目标；内容搜索包含已捕获回复文本。`av`／`BV` 链接使用系统默认浏览器。

启用时间后，事件使用收到的事件时间戳，具体排版由主题决定：原生默认的弹幕与互动随文显示，轻语气泡通常在气泡外右下方显示时分；系统事件仅开播、下播显示时间，大航海成就不显示时间。回看独立保留时间。

## 实现与验收

主要入口：`src/components/EventRow.tsx`、`src/events/liveEventLocation.ts`、`feedScroll.ts`、`eventIdentity.ts`。

验收两种追加方向的最新／标记／上下文定位、定位后持续收新事件、重复原始 ID 的单条标记与收藏、用户筛选退出、回复搜索及区域独立标记。

## 样式与快捷菜单

现场事件大类与细项只由现场筛选控制，不受主题事件显示开关约束；主题仍控制外观与信息元素。预览选择现场目标时使用相同规则。

悬停快捷菜单的高亮覆盖整条事件，包括头像、正文和时间区域；操作图标保留独立热区，不能被事件高度或裁切边界截断。查看上下文后恢复对应分类流中的目标事件和阅读位置。

## 系统提醒与特效

顶部紧急提醒按事件先后更新，房间封禁优先于直播切断。有可靠期限时显示解禁时间和剩余时长，倒计时结束后等待平台状态确认，不自行宣布解禁；重新开播结束此前提醒，历史记录仍保留。

现场切换双区、多区或调整布局不会重新播放已处理事件的礼物与大航海特效。事件列表和特效播放各自维护状态，布局变化不代表重新收到事件。

## 发送弹幕

现场“弹幕／弹幕与互动”标题旁的对话气泡加号图标打开悬浮输入框，不挤压列表。使用当前登录账号和当前直播间，连接未就绪时不可发送。Enter 发送，Shift+Enter 换行；中文输入法选字确认不会发送。收起后保留同账号、同房间的草稿，切房隔离内容和回复对象；切房、断线或退出登录会取消尚未发出的请求，已发出的请求不能撤回。

事件菜单的“回复该用户”打开同一个输入框，显示回复对象，支持取消或更换；可添加为快捷动作，不更改已有快捷项。隐藏弹幕分区后，其他现场事件的回复仍能打开共用输入框。回看、只读副窗口和输出页面不提供该发送操作。

表情面板每次打开输入框时默认收起，分类使用包封面图或图标切换，悬停提供名称；分类条支持滚轮横向浏览，到达边缘后不拦截面板滚动，保留触控板及键盘操作。小表情使用32px格、24px图片，大表情使用48px格，通用长条表情行高28px，图片保持原比例。读取当前账号在直播间可用的小表情、通用长条、房间、粉丝团、大航海、充电及个人表情包，保留平台发送权限。小表情在光标处以图片插入正文，发送和复制时使用对应触发词；字数按实际发送文本占用计算。独立大表情点击即发送，不需要再次确认，也不删除文字草稿或回复对象；回复状态下发送大表情不附带回复参数。发送大表情时复用近期加载的权限结果，表情加载失败可刷新重试，不影响文字发送。

输入框顶部标题行常驻显示当前佩戴的粉丝牌，不另起一行重复用户名；收起状态和展开列表复用原生 FanMedalBadge 的等级色阶、字重、圆角与未点亮灰色。展开可查看并切换粉丝牌，切换成功后刷新表情权限；佩戴不等于点亮，不自动点亮粉丝牌。读取失败可重试，佩戴结果不明确时提示刷新确认。

连接就绪时在后台准备发送所需信息与网络连接，准备失败不影响进房和接收事件，也不依赖 OBS 开启。打开输入框时保持准备结果新鲜；近期登录结果和表情列表共用五分钟内的结果，手动刷新及切换粉丝牌会更新对应表情权限。准备就绪后，文字和已加载的大表情点击直接提交，不在点击后重复查询。账号变化不复用旧身份，平台返回登录失效时清除准备结果，下一次操作重新核实；发送请求不自动重试。

发送结果使用“正在发送…”、“已发送”及具体原因提示。失败保留内容，不能确定是否发出时提醒先查看直播间，不自动重发。列表与档案只消费真实收到的事件，不插入模拟发送记录。发送成功提示不保证所有观众已经看到。
