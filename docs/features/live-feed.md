# 现场事件流

## 范围与筛选

现场支持双区／多区，弹幕与互动、礼物、醒目留言、大航海按区域展示。分类“全选／取消全选”调整一级及互动／礼物细分分类，不清除关键词、价格阈值或布局。

现场保留程序本次会话收到的全部事件，不按副窗口或 OBS 的显示容量截断；输出淘汰、到期和分类切换不删除现场历史。

现场过滤不影响档案原始事件。[礼物阈值和金额](event-display.md#礼物与金额)与[回看查询](review-archive.md#时间线与检索)各有明确范围。

## 阅读与定位

信息流行为提供“顶部追加／底部追加”，同步现场和副窗口，不改变回看排列。最新入口随追加方向位于对应一端，箭头方向一致。

查看上下文在有筛选条件时提供：退出文本／用户检索，在原分类信息流中定位单条目标。定位或跳转到标记后停止跟随，新事件不能推走阅读位置；回到最新重新进入跟随。现场定位使用实测行位置并等位置稳定后完成，不恢复旧筛选视图的滚动位置。

标记是每个事件区域最多一个阅读位置，新标记替代该区域旧标记。目标以事件行身份确定，不能把同 UID 的所有事件标记。标记不进入档案，也不与回看标记建立关联。

## 事件交互

更多菜单按“筛选该用户 → 语音播报 → 添加／更改昵称 → 打开用户主页 → 收藏事件 → 标记事件”排列；有筛选时增加“查看上下文”，用户筛选可明确退出。

昵称按 UID 共用，在用户名后括号显示，TTS 是否朗读由对应开关控制。收藏按事件稳定身份保存，不按 UID 收藏全部消息；编辑交互见[收藏](favorites.md)。语音播报只进入 TTS，不触发个性播报。

快捷按钮可从播报、筛选、收藏、标记中选最多三个并拖动排序。收藏和标记状态持续显示，筛选不累积成事件状态。

头像可点击预览。结构化回复的 `@用户名` 可筛选目标，普通文本 `@` 不伪造目标；内容搜索包含已捕获回复文本。`av`／`BV` 链接使用系统默认浏览器。

启用时间后，事件使用收到的事件时间戳，具体排版由主题决定：原生默认的弹幕与互动随文显示，轻语气泡通常在气泡外右下方显示时分；系统事件仅开播、下播显示时间，大航海成就不显示时间。回看独立保留时间。

## 实现与验收

主要入口：`src/components/EventRow.tsx`、`src/events/liveEventLocation.ts`、`feedScroll.ts`、`eventIdentity.ts`。

验收两种追加方向的最新／标记／上下文定位、定位后持续收新事件、重复原始 ID 的单条标记与收藏、用户筛选退出、回复搜索及区域独立标记。

## 样式与快捷菜单

现场事件大类与细项只由现场筛选控制，不受主题事件显示开关约束；主题仍控制外观与信息元素。预览选择现场目标时使用相同规则。

悬停快捷菜单的高亮覆盖整条事件，包括头像、正文和时间区域；操作图标保留独立热区，不能被事件高度或裁切边界截断。查看上下文后恢复对应分类流中的目标事件和阅读位置。
