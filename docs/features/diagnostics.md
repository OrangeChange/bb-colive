# 诊断与日志

## 目的与日志流

收益分窗的 `gift-only`、`superchat`、`guard` 与组合窗 `gift` 使用相同诊断接收、关闭准备及退出刷盘机制。窗口记录带实际原生标签，覆盖锁定、几何、房间握手和固定候选数量；环境快照包含显示方式、当前选择、最近非空组合，以及各收益窗的开启、锁定、房间、代次、ready、pending和固定候选数量。托盘礼物窗开关展示所有收益窗的总状态。

诊断用于从接收、适配、筛选、投递、渲染到播报追踪问题，不是档案备份。主端统一分配应用会话及 seq，副窗口提交后由主端写入一次，保留房间／连接／事件／请求关联。

| 流 | 内容 |
| --- | --- |
| app | 启动、连接、接口结果、适配、去重合并、过滤原因、投递、操作和异常 |
| source | 实际收到的命令、原始内容、接收时间与关联信息 |
| render | 主／副窗口实际文字、资源引用与加载结果、区域、new／update／remove 及样式动画信息 |
| tts | TTS／个性播报匹配、过滤、合成、解码、设备、播放、取消与失败 |
| markers | 问题标记时刻、备注、关联和收集窗口 |

旧 conn／ui 日志不再由当前运行系统读写或导出，历史包只作为旧证据。未知命令可保留 source，不强行渲染成系统事件。render remove 区分列表回收、过期与实际移除。

副窗口固定展示使用既有 window 诊断的 `sticky` 动作，记录候选、资格不足、撤回、开奖、启停、恢复与到期；主端候选记录实际支付、展示金额、首条发生时间、结束时间及有效候选数，不记录卡片正文。副窗口功能快照版本2包含有效 `settings.general.stickyEvents`。固定投影不重复进入普通事件的 render 统计、source、档案或 TTS。

## 问题标记与导出

“标记问题”以确认时刻收集前 2 分钟、后 3 分钟，与现场阅读标记独立。collecting／complete 在导出时重新计算，后续时间未到不能宣称已完整收集。

提供最近 24 小时和完整日志包：前者按导出起点逐条限制时间，后者覆盖本机保管期内现存日志，均不是无限历史。文件名含本机五位短标识及导出时间，已存在目标加序号，不覆盖。

包内附 environment、settings、diagnostics、feature-manifest 与 manifest。环境含版本、Git 构建标识、WebView2 实际版本来源、窗口／全部显示器几何和缩放、音频设备及房间；设置提供有效脱敏值；诊断含刷盘结果与健康计数；功能清单同时列声明、实际活动、取得／缺失快照和安全设置变更。

凭据、Cookie、Token、API Key、Authorization、本地路径和音频内容排除。用户消息原文仍可能在 source／render 内出现，诊断不是匿名统计数据。

导出先等待副窗口诊断接收屏障，再刷盘；后台读取解析压缩，界面显示进度、预计时长与最终路径，missingSnapshots 在包内和界面使用同一列表。文件写入成功不代表诊断覆盖完整，仍需看缺失、读取失败、解析失败、截断与丢弃。

## 写入、保管与退出

记录约每 2 秒异步刷盘，单记录器待写上限 1000（含在写），显式 flush 捕获已接受记录；失败保留重试，不能阻塞直播或播报。failed／flushed 表示本次结果，pending 含在写，writeFailures／droppedRecords 为累计。

普通流保留 7 天或合计 64MB，source／render 保留 3 天或合计 512MB。启动时检查，此后每分钟轮换最旧的非活动文件；最近一天仍在写入的文件不清理，近期文件本身超限时保留容量提醒。容量达到保留上限显示黄色提醒，不等于写入停止；实际丢弃记录显示红色提示。写入异常和待写队列已满分别显示，不将普通待写记录误判为队列已满。“记录正常”只表示未检测写入失败或容量丢弃，不证明上游无丢失。

标题栏和托盘退出共用准备流程：等待导出、断开连接和刷档案、副窗口关闭准备、接收屏障、最终日志刷盘，再停音频并退出。副窗准备与接收屏障各最多 3 秒，串行执行；失败不标记 clean，仍允许最终退出。隐藏到托盘不执行退出。

## 新功能接入与验收

在 `featureCatalog.ts` 的生产功能集合及目录登记功能 ID、面板、流、阶段、snapshot schema 和 failure hooks。请求、成功、失败、取消、渲染边界记录关联字段，快照反映有效脱敏设置，复用现有详细流，不逐条复制一份功能日志。

`assertProductionFeatureCoverage()` 检查生产集合与目录差集；登记不能代替实际操作记录。新增功能测试覆盖成功和失败、快照嵌套键、关联 ID 及打包资源。

云端记录恢复登记为独立功能，记录面板打开、服务器连接、恢复开始、完成、失败和暂停；不记录服务器地址、身份码、下载内容或恢复事件正文。档案快照用于确认写入结果，令牌不进入诊断包。

实际操作后核对两种诊断包：声明及活动存在，missingSnapshots 为空，关键链路可关联，manifest 无未解释的失败、截断和丢弃。回看快照包含三维场次状态、原因、SQLite／writer 健康、查询／阅读与操作摘要，不带完整数据库。

实现：`src/diagnostics/`、`src/archive/archiveDiagnostics.ts` 与 Rust 诊断导出。能力限制与尚待原生验收见[项目状态](../project-status.md)。
