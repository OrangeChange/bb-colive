# 浏览器输出

在样式 → OBS设置为房间保存主题与显示缩放，复制地址到浏览器或OBS浏览器源。各配置独立绑定房间和主题；同房间输出复用主程序已有连接，不为每页重复采集。不同房间使用各自的事件、粉丝牌事实和礼物资源。

四类主题的 OBS 输出按所应用主题的事件大类和细项筛选，不跟随现场分类按钮；共用输出容量、定时消失、合并、事件动画、内容对齐和最新位置。仅保留主题支持能力与模式特色。主流、置顶和独立礼物特效分别维护生命周期，隐藏项不占主流容量。现场无输出容量限制，回看不进入该流程。

网页背景始终透明，事件配色使用配置的跟随软件／浅色／深色选项；链接显式明暗参数优先，Laplace 场景规则见 [UX-CONTRACT.md](../specifications/UX-CONTRACT.md#主题调整与-obs-输出契约)。每页独立阅读，事件和样式同步；滚离最新端暂停跟随，回到最新后恢复。置顶只用于副窗口和OBS，超出宽度时使用鼠标滚轮横向滚动，不显示滚动条。

“OBS礼物特效”默认关闭，独立于现场及收益窗开关。开启后播放后续匹配事件，共用原有播放器与队列；重复通知、主题更新、新开及重连不补播。视频、配置及配置引用图片由同源服务提供。换主题保留当前播放，换房取消，关闭开关清空等待项。礼物动图是事件内容，和独立特效分别控制。

配置使用稳定短码，修改名称、房间和主题不更换地址。`room` 与 `mode` 链接参数只覆盖本页，不反写保存值；失效配置在软件 OBS 管理中提示，不静默使用其他配置；OBS 画布不输出错误或空状态文字，保持透明。

大航海特效与礼物特效分开控制，购买及成就使用已解析的官方资源。

## 样式预览

右侧样式预览的“打开预览页”打开独立软件预览窗口，“复制预览链接”提供唯一固定网页地址。二者跟随当前样式预览的事件、草稿、目标、配色、播放与速度，阅读位置各自独立。固定预览链接不按房间或兼容模式拆分，不承载工具栏，背景始终透明。它和直播间OBS配置输出是不同用途。预览连接中断时保留已有画面，通过独立状态栏提示；重连后继续同步。OBS 输出不展示这条预览状态栏。
