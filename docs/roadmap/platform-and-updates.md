# 平台与更新规划

状态：待实施。当前正式支持 Windows 10/11 x64；继续使用 Tauri，不因跨平台规划替换现有技术栈。

## 平台边界

事件语义、金额、收藏、筛选、档案与交互结果应跨平台一致。字体外观、系统窗口边框、音频设备枚举等允许平台差异，但动作与设置含义一致。

macOS／Linux 尚未完成完整构建验收。后续接入需要分别处理 TTS 引擎、默认及固定音频设备、窗口逻辑尺寸／DPI、字体、原生系统交互、代理／证书及数据路径，不能把 Windows 实测结论直接当成其他平台通过。

WebView 基线、系统版本、显示器缩放及输入法需纳入测试；运行环境报告使用实际 WebView 版本。现有跨平台调查、具体矩阵和技术路线保存为历史规划资料，实施前核对当前代码，不照搬旧版本待办。

当前前端能力与候选内核实测见[前端兼容约定](../development/frontend-runtime-compatibility.md)；候选版本不等于已完成整机验收的最低版本。

## 双源分发

Gitee 优先、GitHub 备用；同一份构建产物分别发布，Release 附件不依赖源码镜像自动同步，不要求个人后端。

首次检查优先 Gitee，后续优先上次成功源。清单或下载失败切备用，清单和程序包来自同一源；不根据语言、IP 地区或定位服务判断。记录源选择、阶段、耗时和失败原因。

## 安装版与便携版

NSIS 为普通安装渠道，后续接 Tauri 自动更新；MSI 若提供则独立渠道。更新只替换程序，不覆盖设置、凭据、SQLite 或日志。清单区分系统、架构与兼容渠道，不能只凭版本号选包。

便携版独立 `latest-portable.json`，下载 ZIP 后提供所在目录入口；首期用户退出后手动解压替换，不自动覆盖运行中的 exe。安装版使用独立清单，不能误下载便携或其他架构包。

每版本只构建并签名一次，同产物上传两个源。保留 Tauri 更新签名，镜像不得重打包。更新功能需接入[诊断](../features/diagnostics.md)的生产登记、快照和请求／下载／安装结果链路。

## 验收

大陆直连、任一源不可达、超时、清单可读但下载失败；NSIS 更新重启及数据保持；MSI／NSIS／便携渠道区分；x64／ARM64 与兼容构建匹配；便携下载、目录打开与手工覆盖。上述能力尚未接入当前版本。
