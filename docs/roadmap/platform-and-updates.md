# 平台与更新规划

当前正式支持 Windows 10/11 x64，继续使用 Tauri。1.1.0 已接入安装版与便携版的软件内更新；macOS／Linux 尚未完成完整构建验收。

## 平台边界

事件语义、金额、收藏、筛选、档案与交互结果应跨平台一致。字体外观、系统窗口边框、音频设备枚举等允许平台差异，但动作与设置含义一致。

macOS／Linux 后续接入需要分别处理 TTS 引擎、默认及固定音频设备、窗口逻辑尺寸／DPI、字体、原生系统交互、代理／证书及数据路径，不能把 Windows 实测结论直接当成其他平台通过。

WebView 基线、系统版本、显示器缩放及输入法需纳入测试；运行环境报告使用实际 WebView 版本。当前前端能力与候选内核实测见[前端兼容约定](../development/frontend-runtime-compatibility.md)，候选版本不等于已完成整机验收的最低版本。

## 已接入的双源更新

自动线路按 IP 国家代码选择，CN 使用国内，其他地区使用国外；定位失败暂用国内。用户可手动切换。自动模式比较两站正式版本，下载备用仅限同版本；手动模式遵循选定线路。

安装版在原安装目录静默更新，便携版原位替换程序文件。两者使用独立渠道标识，保留数据、配置和自定义主题；下载完成后由用户选择重启更新。每版本使用同一份构建产物分别发布到两站，更新包使用 Minisign 签名，清单按站点提供对应下载地址。

更新操作与发布格式见[构建与发布](../development/build-and-release.md#软件内更新)。其他架构与安装渠道随对应平台接入再确定。
