## 封面状态的当前边界

适配层暂时只生成中性文案：`直播封面状态发生变化` 或 `直播间内容审核状态发生变化`，由系统提醒模块承载。不会根据单个 `audit_status` 值擅自显示“更换成功”或“审核通过”。`ROOM_CONTENT_AUDIT_REPORT` 只有在报文中的 `room_id` 与当前连接房间一致时才进入事件流；不匹配或缺失房间号的报文只保留在原始日志中。后续需要继续采集至少两类以上样本，并将状态值与页面实际反馈、封面 URL 变化、驳回理由和时间顺序对照后，再决定是否细分文案。

## 归档与显示的关系

“归档”不是删除原始数据：历史抓包中的 `ConnectionLogger` 曾记录完整原始报文；当前相同职责由 `source-*` 诊断流承担。适配层返回 `null` 的命令不会进入事件数组、现场各区域或系统提醒；已知的中性审核事件进入统一事件模型，并由提醒模块显示；仍未识别的命令保留 source 诊断记录，但不再进入铃铛提醒，避免平台内部信令污染消息通知。
