# B 站直播 API 错误码

> 早期调查证据，不作为当前功能规范。


本文件记录 danmu-app 调用 B 站直播接口时遇到/确认的错误码，用于用户报错排查与日志对照。

> 维护原则：只录入真机验证或从 B 站官方行为确认的码；未验证的第三方清单不照搬。
> 后续真机遇到新码时补充到下表，并同步更新 `src/protocol/api.ts` 的 `API_ERROR_TEXT`。

## 错误码对照表

| code | 含义 | 触发场景 | 用户提示 | 处理建议 |
|------|------|----------|----------|----------|
| 60004 | 房间不存在 | `room_init` 查不到房间号 | 房间不存在，请检查房间号 | 检查房间号是否正确；链接型输入走 `keyFromUrl` 解析 |
| -352 | 风控拦截 | 请求被识别为爬虫（多因缺 wbi 签名 / unsafe-headers） | 请求被风控拦截，请稍后重试 | 确认 wbi 签名与 `unsafe-headers` feature；稍后重试 |
| -412 | 请求被拦截 | 短时间请求过频 | 请求被拦截，请稍后重试 | 降低请求频率；稍后重试 |
| -101 | 登录已失效 | SESSDATA 过期或无效 | 登录已失效，请重新扫码登录 | 引导用户重新扫码登录 |
| -400 | 请求参数错误 | 请求参数缺失或不合法 | 请求参数错误 | 检查接口调用参数 |
| -1 | 接口暂不可用 | 服务端临时异常 | 接口暂不可用，请稍后重试 | 稍后重试 |

## HTTP 状态码（非业务码）

| 状态 | 含义 | 处理 |
|------|------|------|
| 403 / 412 | CDN 拦截 | 请求被拦截，请稍后重试 |
| 非 JSON 响应 | 服务响应异常 | 服务响应异常，请稍后重试 |

## 字段位置

- `src/protocol/api.ts` 的 `ApiError.friendly`：按 code 映射的用户可读文案
- `src/protocol/api.ts` 的 `API_ERROR_TEXT`：code → 文案映射表（新增码在此维护）
- `src/protocol/connection.ts`：UI 显示 `friendly（code）`；完整技术细节保留在 `ApiError.message`，供后续日志面板

## 用户体验约定

UI 错误提示格式：`人话文案（code）`，如「房间不存在，请检查房间号（60004）」。
未识别的码显示 `接口异常（code）`，便于用户上报后定位。
