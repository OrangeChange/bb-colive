# 自动弹幕发送标记

2026-10-04，房间21696950的天选口令为“国庆快乐呀！”。本次连接原始样本中，同文弹幕718条，643条的 `info[0][9]` 为2，75条为0；“老板大气”527条及其他3610条均为0。样本统计为当时日志截面，不是整场总量。

Chrome中的Laplace对照页开启 `showAutoDanmaku=true`，实际显示该口令。页面已加载的 `gift-effect-player-B9XQm1oJ.js` 中，弹幕解析函数将 `info[0][9]` 映射为 `sendType`；普通及历史消息过滤均在该字段是数值且非零、显示自动弹幕未开启时过滤。该源码与本次样本吻合，不按口令文字判定。

[blivechat解析](https://github.com/xfgryujk/blivechat/blob/dev/frontend/src/api/chat/ChatClientDirectWeb.js)使用 `Boolean(info[0][9])`，并附加固定文案识别。客户端只保留原始数值及非零判断，不引入固定文案名单。各非零取值的精确类别尚未确认，值0的同文弹幕不能由本次证据认定为手动发送。

## 显示与验收

全局“显示自动弹幕”默认开启，各显示入口复用相同判断。公共子类为 `.chat-auto`，继承 `.type-chat`；不新增可见徽章。弹幕窗保留未合并缓冲，先过滤后合并，开关切换重新生成显示行，原始记录及导出不变。
